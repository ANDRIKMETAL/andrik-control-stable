Стрим Facebook

Facebook работает через независимый R1356 relay. Ключ перед START синхронизируется с VPS автоматически; YouTube и Studio не перезапускаются. Для Facebook работают отдельные START / STOP без лишних служебных блоков о ротации сигнала.

🕒 Автоматический запуск Facebook

В 13:55 сбрасывается счётчик аварийных рестартов R1279, если защита включена и Facebook остановлен; в 14:00 запускается только Facebook RTMPS-ветка по Братиславе. Защита остаётся включённой, таймера STOP нет. Ручные кнопки отдельно.

Persistent Stream Key

Ключ хранится зашифрованно в Secure Control. После «СОХРАНИТЬ» контролька сама синхронизирует его в защищённый VPS-конфиг — без restart радио.

SECURE
https://www.facebook.com/live/ingests/ — тестовая веб-страница. Для VPS используется RTMPS Server URL выше + Persistent Stream Key.
Текущий сохранённый ключ менять не нужно, если Facebook уже работает.

Защита от повторных запусков Facebook

Если Meta завершит эфир и Facebook FFmpeg начнёт снова и снова подключаться, агент остановит только Facebook после 3 неожиданных рестартов за 10 минут. YouTube и радио не перезапускаются.

R1279
Настройка сохраняется на VPS и работает без открытой контрольки. Включение не остановит действующий эфир.

Ручное управление

START сначала подтягивает последний сохранённый ключ на VPS, проверяет независимый R1356 relay и только затем запускает Facebook. STOP выключает только Facebook FFmpeg.
