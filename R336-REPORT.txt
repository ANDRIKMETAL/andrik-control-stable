ANDRIK Control R336 — LIVE ECOSYSTEM MAP
Date: 2026-08-09
Base: R335 — R334 SINGLE TITLE MOBILE FIT SAFE FULL

PURPOSE
Turn the existing YouTube country map into one stable multi-layer LIVE ecosystem map without changing the accepted R335 map geometry.

NEW MAP LAYERS
1. ◎ ALL — combined ecosystem signals by country.
2. 🌐 SITE — site users by country for 30 days; new first-party city/coarse-location points accumulate after R336 deployment.
3. ▶ YOUTUBE — existing YouTube views by country for 28 days; existing monthly archive and 7-day country-growth controls remain on this layer.
4. ♪ MUSIC — MP3 download / listening actions for 30 days, with city/coarse-location points where available.
5. 🔔 PUSH — active non-owner push subscriptions with known geography.

LIVE MODE
- New first-party activity stream keeps the latest 60 minutes of site/music/social actions in the existing D1 event table.
- SITE and ALL can show brighter pulsing LIVE points for recent site visits.
- MUSIC and ALL can show brighter pulsing LIVE points for recent listening / MP3 actions.
- ALL can also pulse for recent Telegram, YouTube, Spotify, Apple Music, SoundCloud and Amazon Music outbound actions.
- Recent point list is capped and the D1 event table retains only the existing short first-party window.

DETAIL LEVEL
- Country markers continue to use the stable existing world map and existing country zoom behavior.
- New city/region detail is overlaid as points when Cloudflare edge geography is available.
- Coordinates are rounded to 0.1 degree before storage (coarse, roughly city-level; not a street/device GPS location).
- No raw IP is stored by the new ecosystem telemetry path.
- The ecosystem data endpoint is owner/admin-only.

TELEGRAM / APP PRIVACY
R336 does NOT scan a visitor's phone and does NOT claim to know whether Telegram is installed.
It records real outbound Telegram link opens from ANDRIK pages. This is a reliable first-party action and is shown in the ecosystem totals / LIVE activity.

SERVER CHANGES (_worker.js)
- Build bumped to R336.
- Extended site_visit_events with event_type, target, country, region, city, latitude and longitude; safe ALTER migrations included.
- Existing site live counters explicitly count event_type='visit', so music/social clicks do not inflate website page-view/user counters.
- Extended push_subscribers with country/region/city and coarse latitude/longitude; safe ALTER migrations included.
- Existing subscription rows preserve known geography; future re-registration/visits gradually fill missing geography.
- New GET /api/control/ecosystem-map (owner/admin authorization required).
- Endpoint returns 30-day site/music/push geography, outbound link counts and a 60-minute recent activity stream.
