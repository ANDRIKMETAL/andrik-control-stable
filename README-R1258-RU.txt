ANDRIK SITE R1258 — RADIO STUDIO MONITOR CONTROL

База: R1257. Исправление камеры/микрофона Host Mode из R1257 сохранено.

Добавлено:
1. В «Радио → Видео эфира / студия» новый отдельный блок «Видео-студия · 5 альбомов».
2. Можно с телефона выбрать и загрузить MP4 студии напрямую в R2.
3. Есть предпросмотр загруженного лупа и кнопка удаления.
4. Новый ADMIN API:
   GET / PUT / DELETE  /api/control/radio-studio-r1321
5. Новый публичный read-only media endpoint для OVH:
   GET / HEAD  /api/media/radio-studio-r1321
6. Файл хранится в R2 под ключом:
   radio/studio/andrik-studio-loop-r1321.mp4
7. Лимит загрузки: 100 МБ. Формат: MP4.
8. В панели явно показано: для пяти официальных альбомов студия имеет приоритет,
   старые широкие фоны остаются безопасным fallback. Covers / Extended / Singles не менялись.
9. Ссылка в основной панели радио переименована в «Видео эфира / студия».

Рекомендуемый мастер студии:
1920×1080 · 25 fps · около 8 секунд · H.264 · без звука · спокойный бесшовный loop.

После установки сайта открыть:
/cache-reset-r1258.html

Затем:
Радио → Видео эфира / студия → выбрать MP4 → «ВЫБРАТЬ / ЗАМЕНИТЬ ВИДЕО СТУДИИ».

ВАЖНО: чтобы OVH начал использовать студию в эфире, отдельно установить сервер ANDRIK RADIO R1321.
