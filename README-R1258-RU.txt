ANDRIK SITE R1258 — RADIO SERVER ZIP → PRIVATE R2

База: R1257. Все изменения R1257 сохранены.

Добавлено:
1. В «Radio Control» новый пункт «📦 Выгрузка сервер ZIP».
2. Можно выбрать ZIP нового сервера эфира прямо на телефоне и выгрузить его в private Backup R2.
3. Серверные ZIP хранятся отдельно: radio/server-zips/.
4. После загрузки создаётся защищённая token-ссылка на скачивание через Worker; сам Backup R2 не открывается публично.
5. Для каждого ZIP есть кнопка «📋 КОМАНДА VPS»: она копирует готовую curl-команду, которая скачивает архив прямо в /home/ubuntu.
6. Для небольших ZIP браузер считает SHA256; команда VPS автоматически проверяет SHA256 после скачивания.
7. Есть список загруженных серверов, размер/дата, скачивание и удаление.
8. Максимальный размер одного server ZIP — 96 МБ.
9. Загрузка ZIP никак не перезапускает радио и не касается работающего VPS.

API:
- GET/PUT/DELETE /api/control/radio-server-zips-r1258 — admin-only управление архивами.
- GET /api/radio-server-zip-r1258/download?key=...&token=... — защищённое скачивание конкретного ZIP на VPS.

После установки сайта открыть /cache-reset-r1258.html, дождаться «Готово», затем открыть раздел «Радио».
