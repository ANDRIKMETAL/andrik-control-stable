ANDRIK SITE R1269 · HOST MIC-ONLY R1396

Что сделано:
- «Режим ведущего» теперь имеет два режима:
  1) 🎤 ТОЛЬКО МИКРОФОН — рекомендуемый;
  2) 📷 КАМЕРА + МИКРОФОН — старый R1319.
- MIC-ONLY требует только микрофон телефона.
- Видео, fullscreen и YouTube RTMPS 2/2 не переключаются.
- Голос отправляется через существующий R2 host-chunk transport к R1396 и подмешивается в тот же master audio.
- Ducking 20–60%, по умолчанию 35%.
- Кнопка микрофона во время LIVE работает как mute/unmute через host-mic-enable-r1396.
- При потере телефона R1396 сам завершает MIC-ONLY и возвращает музыку на 100%.
- Старый camera+mic R1319 сохранён без удаления.

ВАЖНО:
Для MIC-ONLY нужен установленный RADIO R1396 и обновлённый VPS web-agent R1269 HOST MIC BRIDGE.
