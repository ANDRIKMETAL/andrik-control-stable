Все остальные файлы сайта, радио, игры, статистики и панели без изменений.

ПРОБЛЕМА
Сервисный экран показывал onesignal-network-error у последнего push, в то время
как центральный Cron имел 0 ошибок. Предыдущая логика дважды ждала ответа OneSignal
до 12 секунд на каждый push, что на фоне других задач могло превысить ограничения
выполнения Cloudflare. При неудаче сообщение фиксировалось как failed, но не
попадало в отдельную гарантированную очередь повтора.

ИЗМЕНЕНИЯ
1. Исходящая попытка OneSignal ограничена 8 секундами вместо двух попыток
   по 12 секунд. Неудачные сетевые запросы и HTTP 429/5xx сохраняются в D1
   push_state (НОВЫХ ТАБЛИЦ НЕТ) с исходным payload и idempotency_key.
2. Существующая отдельная задача релизов, работающая каждые 5 минут, выполняет
   максимум одну попытку повтора в конце цикла. Не нужно менять Central Cron
   и Cron Triggers.
3. OneSignal повторно получает ТОТ ЖЕ idempotency_key, поэтому повторы одного
   события не должны создавать дубли. Если уже есть запись о принятии того же
   уведомления, лишняя запись очереди удаляется без второго запроса.
4. После принятия OneSignal восстановленная отправка заносится в push_history;
   для комментариев и релизов обновляются соответствующие маркеры событий.
5. Для повторов действует небольшая экспоненциальная пауза, ограничение числа
   повторов и время хранения до 24 часов. Старые накопленные ошибки, возникшие
   ДО установки R1505, автоматически не появляются в новой очереди.
6. Ответ OneSignal HTTP 400/401 и другие неретрабельные 4xx не повторяются
   автоматически — это конфигурационная проблема, её надо диагностировать.

- Состояние YouTube, отметки старых уведомлений и подписчиков.

ОГРАНИЧЕНИЕ
Тестов в настоящем Cloudflare / OneSignal в этом архиве нет. Они потребуют
проверки после установки. Принятие OneSignal не гарантирует отображение
уведомления Android — для этого нужны разрешения и статус доставки устройства.
Если последняя ошибка сохраняется, смотреть более свежую запись Push history
и системный лог onesignal-retry-recovered-r1505 / onesignal-retry-expired-r1505.
