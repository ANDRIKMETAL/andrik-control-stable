ANDRIK R1533 — MANAGER

Установка

1. В «Обновлении» контрольки выбери ANDRIK-R1533.zip, укажи R1533 и дождись Deploy.
2. Открой «AI Агенты». Карточка ANDRIK MANAGER находится вверху.
3. Если GUARD и WATCH уже подключены, MANAGER начнёт с их последних отчётов.
   Если агент ждёт подключения, MANAGER покажет задачу со ссылкой на его карточку.

MANAGER работает в существующем Worker сайта и использует его базу D1.
Установка на VPS и платный API не требуются. Агент не меняет файлы VPS
и не запускает команды. В задачах приведены команды диагностики.
Сводка новых срочных задач приходит в уведомлениях владельца через OneSignal.
Нажатие открывает MANAGER. Сводки отправляются не чаще одного раза за пять
минут. Для них используется существующая подписка Android.

Задачи

• Срочно — подтверждённый сбой радио, заполнение диска от 95% или RAM от 95%.
• Проверить — диск или RAM от 85%, CPU от 90% в одном замере, ошибки служб,
  FFmpeg и сигнала. Для радио учитывается, какой из двух отчётов новее.
• Планово — старые временные файлы и неполные замеры.
• Подключение — агент ещё не привязан к контрольке.

При поступлении нового отчёта MANAGER обновляет соответствующую задачу.
Сообщения GUARD и WATCH об одном сбое радио выводятся в одной карточке.
Штатно выключенный эфир отображается в состоянии WATCH.

«Взять в работу» сохраняет статус в контрольке. Если отчёт устарел, задача
остаётся открытой со статусом «Ждёт замера». Новый отчёт с нормальными
показателями закрывает задачу. Повтор проблемы открывает её снова.
В списке закрытых хранится последнее состояние по каждой проблеме.

Отчёты GUARD считаются свежими до 5 минут, WATCH — до 2 минут.
На открытой странице сводка обновляется каждые 30 секунд.
«Скопировать сводку» копирует состояния агентов и открытые задачи для разбора.
