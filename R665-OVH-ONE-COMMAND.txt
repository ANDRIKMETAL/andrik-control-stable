ANDRIK RADIO R665 — OVH AGENT

После загрузки/деплоя R665 на сайт один раз выполни на OVH в Termius:

curl -fsSL https://andrikmetal.com/radio247/vm-lite/install-ovh-agent-r665.sh | sudo bash

Что делает команда:
- НЕ трогает pairing/token;
- заменяет только web-control agent на R665;
- убирает зависимость от /usr/local/sbin/andrik-youtube;
- включает native encoder STOP / START / RESTART / STATUS через systemctl;
- перезапускает только andrik-radio-web-control.service;
- текущий radio service не перезапускает при установке.

После строки:
ГОТОВО ✅ OVH RADIO AGENT R665 УСТАНОВЛЕН

открой:
https://andrikmetal.com/cache-reset-v55-00-final-r665.html

Затем в Control → Радио нажми «ЗАПУСТИТЬ СТРИМ».
