ANDRIK R1277 · FACEBOOK CONTROL FIX

Что изменено:
1. Убран весь блок «Авто-ротация».
2. В карточке состояния убрано поле «До ротации 7 ч». Вместо него теперь «ВХОД МБ».
3. Счётчик «RESTART / ROTATE» заменён на честный «RESTART».
4. График Facebook теперь умеет восстанавливать Mbps по inputBytes, если сервер прислал нулевой mbps.
5. Если сервер вообще не прислал телеметрию, страница пишет, что точки от сервера отсутствуют, вместо вводящего в заблуждение нуля.

Установка:
— загрузить этот полный ZIP через штатное обновление сайта;
— затем открыть https://andrikmetal.com/cache-reset.html ;
— обновить страницу Facebook control принудительно.
