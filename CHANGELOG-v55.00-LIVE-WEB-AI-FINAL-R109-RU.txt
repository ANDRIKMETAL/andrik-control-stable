ANDRIK Control v55.00 FINAL R109 — ADMIN POLISH + VERSION SYNC + YOUTUBE EVENT CONTROL

АДМИН-ПАНЕЛЬ
1. Плавающая кнопка «Обновить» опущена в свободную нижнюю правую зону.
2. Для футера и подписи возврата оставлена безопасная область — кнопка не закрывает карточку «Обсуждение» и текст.
3. Описания четырёх разделов показываются в две строки без преждевременного обрезания.

ЕДИНАЯ ВЕРСИЯ
4. Добавлен единый источник версии R109 для всех активных страниц Control.
5. Синхронизированы футеры: Главная, карта, Служебное, Мониторинг, Релизы, Обсуждение, YouTube, ответы и обновление сайта.
6. Worker, Health API, System API и Site Updater возвращают одну версию R109.

YOUTUBE / PUSH
7. Добавлен компактный «YouTube Event Control»: комментарии, ответы, лайки, подписчики, очередь и ошибки.
8. Кнопки: «Проверить сейчас», «Повторить очередь», «Открыть журнал».
9. Публичный подписчик считается обработанным только после успешного ответа OneSignal.
10. При ошибке push claim освобождается, поэтому подписчик повторяется на следующем Cron.
11. Лайк при ошибке OneSignal больше не теряется: high-water возвращается к прежнему значению, claim освобождается, событие повторяется.
12. Лайки сверх лимита одного Cron остаются в очереди, а не помечаются обработанными.
13. Сводка YouTube показывает отдельно attempted/sent/failed/queued для комментариев, подписчиков и лайков.

РЕЛИЗ ANDRIK
14. В разделе «Релизы» добавлен компактный центр следующего альбома «ТРИКА» с обратным отсчётом до 20.08.2026.
15. Показываются тексты проекта, синхронизация и готовность push-аудитории без фиксации неподтверждённого числа треков.
16. Быстрые кнопки: Тексты, YouTube, Push, Открыть сайт.
