ANDRIK CONTROL R1232

1) Состояние VPS / OVH
- Нагрузка VPS / эфира
- Диск VPS
- VPS Disaster Recovery
теперь находятся под одним общим спойлером.
В закрытом состоянии сразу видно текущий статус: OVH ONLINE / OVH OFFLINE.

2) MP3 PCM %
- процент в Watchdog больше не показывает 108%, 205% и т.п. как обычный процент;
- рабочая шкала ограничена 100%;
- превышение показывается отдельно: «+N% выше порога».

3) График посещений
- текущая красная точка увеличена;
- текущая красная цифра крупнее, жирнее и сдвинута вправо от точки;
- красный halo/ring теперь рисуется под цифрой, а не поверх неё;
- соседние жёлтые столбики разводятся по X, чтобы меньше накладываться;
- соседние столбики чередуются: жёлтый / оранжевый, сохраняя 3D-грань.
