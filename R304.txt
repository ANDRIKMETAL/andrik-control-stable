R304 — PORTRAIT COUNTRY MAP FRAME MATCH

Base: R303 (which is R302 + the portrait map-height correction).

Only layout change:
- In portrait mode with a selected country, the green map frame now uses exactly the same 270–286 px responsive height rule as the normal overview map.
- The selected-country yellow card therefore moves down naturally by the extra map height.
- The inner canvas/stage is locked to 100% of the frame height so legacy R275 focus rules cannot leave the visual map shorter than its frame.

Not changed:
- map zoom/transform/points/animations;
- country actions/buttons;
- scroll/swipe behavior;
- YouTube, push, Cron/Guard bridge, Worker/API;
- updater/install flow.
