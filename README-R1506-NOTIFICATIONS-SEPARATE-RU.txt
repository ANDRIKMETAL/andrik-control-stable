ANDRIK SITE R1506 — OWNER NOTIFICATIONS SEPARATE
Дата: 26 октября 2026

Основа: SITE-R1505-PUSH-RETRY-FIX-FULL.zip (пользовательский/предыдущий архив).
Изменён только _worker.js; добавлена эта инструкция и пересчитан установочный SHA-1-манифест.

ПРОБЛЕМА
Для разных событий владельца OneSignal получал одинаковые collapse_id и
web_push_topic. Поэтому уведомление о Латвии могло заменить Чехию, а
следующее уведомление ANDRIK — предыдущую страну, хотя доставка работала.

ИСПРАВЛЕНИЕ
1. Каждое новое событие владельца получает собственный collapse_id и web_push_topic,
   вычисленные из уже существующего стабильного idempotency_key события.
2. Android-группировка и iOS thread_id больше не назначаются автоматически
   для сообщений владельца: разные события не складываются в одну группу.
3. Повторная отправка того же события сохраняет исходный idempotency_key.
   Исправление R1505 (очередь повторов) оставлено без изменений.
4. Для широковещательных push сохранены явно заданные параметры; если они
   не заданы, используются отдельные устойчивые темы для каждого события.
5. D1, Cron Triggers, центральный Worker, радио, игра и статистика не менялись.

ВАЖНО
- Android может самостоятельно очистить уведомление (вручную или по настройкам);
  сервер не способен гарантировать вечное нахождение уведомления в шторке.
- Уведомления, отправленные ДО установки этой версии, не восстанавливаются.
- Неполностью доставленные push, уже лежащие в очереди R1505, сохраняют
  прежние параметры в своём payload при последующей отправке.
- Нужна реальная проверка двумя разными уведомлениями после установки.

УСТАНОВКА
Устанавливается обычным ZIP-обновлением Control ANDRIK.
НЕ менять центральный Cron и три расписания */2, */5, */15.
Перед повторной установкой после HTTP 524 проверь GitHub Deploy, чтобы не
создать второй Commit, если первая попытка уже завершилась.
