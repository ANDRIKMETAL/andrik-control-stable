Date: 2026-08-15
Base: R443

1. R2 ALBUM ZIP BUILDER
- Replaced the R443 Worker-side whole-album ZIP stream builder.
- ZIP is now assembled in the admin browser with STORE entries (no MP3 transcoding).
- Browser calculates CRC32 and uploads the resulting ZIP to R2 in uniform 8 MiB multipart parts.
- Worker only proxies source MP3 and handles R2 multipart start / part / complete / abort operations.
- This avoids buffering 133–148 MB albums in Worker memory and avoids per-byte CRC CPU work inside Worker.
- Source MP3 objects are never modified.
- Duplicate numbered tracks are detected. When multiple objects share one track number, the canonical localized/metadata-rich version is used in the archive.
- Public album ZIP download endpoint remains /api/music/album-download?album=<slug>.
- Public ZIP availability endpoint added: /api/music/albums/status.
