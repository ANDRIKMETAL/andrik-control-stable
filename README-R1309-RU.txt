ОГРАНИЧЕНИЯ
— Эта сборка не выполняет деплой сама. После установки первый цикл мониторинга заполняет каталог; старые комментарии импортируются постепенно.
— YouTube Data API может не выдавать автоальбомы OLAK5uy и комментарии к Topic-записям. В таком случае нужны индивидуальные Video ID треков (экран диагностики), а отключённые комментарии получить невозможно.
— YouTube API возвращает только агрегированные лайки. Нельзя узнать, кто поставил лайк, или гарантировать мгновенные уведомления.
— Открытие Spotify через Android сохраняет существующие data-force-app атрибуты. Нативное воспроизведение зависит от платформы/доступа YouTube.
