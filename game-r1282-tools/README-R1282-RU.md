# ANDRIK GAME R1282 — RUINS OF EPOCHS / РУИНЫ ЭПОХ

Статус: тестовая сборка. Изменяется только игровой шестой уровень; другие главы сохраняют прежнюю механику. Это не подтверждённый Android-релиз.

## Что действительно реализовано
- Новый отдельный мир храма времени в Three.js: циферблаты, гигантские кольца, бронза, плиты, пропасть, парящие обломки, маятник, руны и три печати.
- Перспективная камера 3/4 (уровень 6); управление остаётся 2.5D — движение по двум осям, без ложного свободного перемещения в глубину.
- Четыре геометрически разных противника: каменный страж, песчаная тень, бронзовый смотритель (снаряды), расколотый колосс (волна).
- Отдельная объёмная модель Хранителя эпох с подвижными руками, ядром и кольцами; три фазы атак.
- FSM босса: ожидание, предупреждение, активная атака, восстановление, окно уязвимости, смена фазы, смерть; один хит за одну атаку, очистка опасных эффектов после смерти.
- Три хронопечати в зале: подходить к пьедесталу и нажать обычную атаку для включения; все три нужны для открытия арены.
- Движущиеся часы/маятник, маркеры атак и необязательный отладочный режим (?ruinsDebug=1).
- Сохранены числовой уровень 6 и кампания [1,2,Портрет,3,4,6,5], где Tetris — последняя глава.
- Статичная геометрия объединена в InstancedMesh для сокращения количества draw calls.

## Ограничения / требуется тест на настоящем устройстве
- Это процедурный 3D, без высокодетальных внешних моделей и PBR-текстур уровня концепт-артов.
- Мобильное управление, WebGL-рендеринг и FPS пока не проверены в реальном браузере. Chromium в тестовой среде заблокировал локальную страницу (ERR_BLOCKED_BY_ADMINISTRATOR); снимки из игрового рендерера НЕ получены.
- Путь пока без новой полноценной физики платформ и восстанавливаемых мостов. Пропасти вокруг проходимого маршрута декоративные, чтобы не ломать действующие коллизии.
- Доработки не покрывают весь объём исходного ТЗ: например, полноценную анимационную модель Лиры, смену всех столкновений и общую систему звуков.
- Фактические 30/60 FPS на Android/ПК не измерены. Не устанавливать на продакшен без предварительной проверки на копии сайта.

## Установка
Рекомендуется: загрузить SITE-R1282-RUINS-OF-EPOCHS-TEST.zip как полный ZIP сайта в место обычного развёртывания (после резервного копирования текущего сайта). После обновления использовать https://andrikmetal.com/cache-reset.html

Если сайт распакован в локальный каталог, можно применить малый PATCH-R1282.zip (распаковать отдельно):
  python3 game-r1282-tools/install-game.py --root /путь/к/распакованному/сайту --check
  python3 game-r1282-tools/install-game.py --root /путь/к/распакованному/сайту

Откат для установленного патча:
  python3 game-r1282-tools/install-game.py --root /путь/к/распакованному/сайту --rollback

НЕ применять установщик к серверу радио/вещания; он предназначен только для каталога статического сайта. Установщик требует точную исходную версию R1281, создаёт резервные копии, при конфликте останавливается без изменений.

## Проверки
- node --check: игровой 3D-модуль, окружение, inline-скрипт игры — PASS.
- node test_ruins_scene.mjs: Three.js построение и конечность координат — PASS.
- node test_boss_state.mjs: последовательность состояний, фазы, задержка смерти — PASS.
- Chromium: заблокирована навигация; визуальный кадр и FPS не подтверждены.
- Сохранения и другие уровни требуют очной проверки.

## Критичные ручные тесты
1) Запустить шестой уровень на копии сайта, проверить мобильную крестовину, что лево/право соответствуют экрану.
2) Пройти до трех хронопечатей (вблизи нажать атаку), проверить, что арена открывается после 3/3.
3) Проверить врагов, прыжок, перекрывающие колонны, HUD, FPS.
4) Провести три полных боя: обычный, с поражением и повтором, с паузой во время атаки.
5) Убедиться, что после победы открыт Tetris и сохранение не сброшено.
6) Проверить City/Ocean/Portrait и работоспособность сайта и радиоплеера.
