R197 — SIGNED OWNER SESSION FOR ANDROID PWA

- Keeps the accepted R195 one-button ZIP installer and visual base.
- Fixes owner authorization persistence after page navigation on Android PWA/WebView.
- Uses one host-only HttpOnly Secure cookie instead of a multi-Set-Cookie response.
- Adds an expiring signed session-token fallback for Android PWA; the raw ADMIN_KEY is never stored.
- Automatically migrates the temporary R196 emergency ADMIN_KEY and deletes the raw stored value.
- Sends the signed token only to same-origin protected /api/ requests.
- Keeps 90-day expiry and invalidates sessions automatically when server secrets change.
- Fixes rate-limit bypass by verifying the signed session instead of trusting a client marker header.
- GitHub two-factor authentication remains enabled and independent.
