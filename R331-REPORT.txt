ANDRIK R331
Base: R330.

YouTube subscriber push reliability:
- Fixed R330 hole: a visible subscriber is no longer subtracted from subscriberDelta
  until its individual push actually succeeds.
- Added generic +N subscriber fallback in the same Cron run if the named push fails.
- Added stale push-once claim recovery for subscriber notifications.
- If the generic count push covers a failed named subscriber push, that subscriber is
  marked covered to prevent a duplicate on the next Cron.
- Added a short-lived visible-subscriber credit so a named subscriber notification that
  arrives before channels.statistics.subscriberCount catches up does not create a second
  generic +1 notification later.
- Subscriber count baseline is still rolled back when OneSignal delivery fails, preserving retry.
- Added R331 subscriber diagnostics to youtube-events status summary.

Safety:
- Player, public home, singles catalog, MP3/WAV editor and R315 admin shell untouched byte-for-byte.
