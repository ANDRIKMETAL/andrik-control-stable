R816 INSTALL

1. Upload/deploy the full R816 archive through the normal ANDRIK site updater.
2. On OVH run:

sudo bash -c '
set -Eeuo pipefail
URL="https://raw.githubusercontent.com/ANDRIKMETAL/andrik-control-stable/main/radio247/vm-lite/install-r816-persistent-rawvideo-single-x264-r814-preserved.sh?t=$(date +%s)"
TMP="$(mktemp)"
trap "rm -f \"$TMP\"" EXIT
curl -fsSL --retry 6 --retry-delay 2 "$URL" -o "$TMP"
grep -q "R816.*PERSISTENT RAWVIDEO" "$TMP" || { echo "R816 installer is not deployed yet; NOTHING CHANGED"; exit 20; }
bash -n "$TMP"
bash "$TMP"
'

3. After R816 READY open:
https://andrikmetal.com/cache-reset-v55-00-final-r816.html

Expected architecture in process proof:
- visual feeder(s): rawvideo/yuv420p, no libx264
- persistent publisher: rawvideo pipe:4 input + libx264 + AAC + dual RTMPS
