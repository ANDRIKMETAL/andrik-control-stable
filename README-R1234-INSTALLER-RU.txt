ANDRIK CONTROL R1234 — SITE UPDATER NO-HANG

Исправление зависания на этапе 5 «Сайт».

Что было:
- спустя 45–90 секунд контролька сама создавала Deploy-kick commit;
- затем могла создать ещё один;
- operationId менялся, пока Cloudflare ещё разворачивал предыдущий commit;
- точная проверка operationId не принимала уже опубликованный R1233 и этап 5 мог висеть;
- повторная установка той же версии создавала ещё один commit и снова запускала ожидание.

Что теперь:
- автоматические Deploy-kick полностью отключены;
- «Проверить Deploy» только проверяет, ничего не коммитит;
- обычная новая версия по-прежнему требует точный operationId;
- только для recovery/reinstall после старых retrigger допускается безопасный fallback по тому же Release;
- finalize использует тот же безопасный fallback;
- существующий pending R1233 из localStorage будет подхвачен и завершён после публикации этого hotfix.
