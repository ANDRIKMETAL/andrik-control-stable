📥 Первичный импорт комментариев

Проверка всех обнаруженных треков порциями по пять. Исторические комментарии попадут в архив D1 без повторных уведомлений. Прогресс сохраняется, даже если закрыть страницу.

Проверяем сохранённый прогресс…

Если YouTube запрещает комментарии для конкретного Topic-трека, причина будет показана здесь. Обход запретов API невозможен. Этот импорт не удаляет прежние записи и не отправляет уведомления о старых комментариях.

Ручное дополнение Video ID (если плейлист API закрыт)

Можно добавить 11-символьные ID роликов, разделяя переносами строк или запятыми. Адрес плейлиста OLAK сюда не вставлять. Существующие ID при сохранении заменяются.
