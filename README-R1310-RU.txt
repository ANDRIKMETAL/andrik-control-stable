ANDRIK R1310 — ИСПРАВЛЕНИЕ ДОСТУПА К МОНИТОРУ РЕЛИЗОВ

ОСНОВА: R1309 FULL. Остальные компоненты сохранены без изменений.

Причина ошибки unauthorized: youtube-releases-admin.html в R1309 не подключал owner-session-r197.js.
В остальных страницах контрольки используется защищённая сессия владельца на 90 дней; вместо ADMIN_KEY в локальном хранилище находится маркер защищённой сессии.
Поэтому прямой запрос с этим маркером без загрузки owner-session-r197.js получал HTTP 401.

Исправлено:
- Подключён имеющийся менеджер авторизации /assets/owner-session-r197.js.
- Запросы нового раздела отправляются с HttpOnly cookie или подписанным токеном из имеющейся сессии.
- Перед первой загрузкой ожидаем, пока проверится сессия, чтобы не было случайного unauthorized.
- Не показываем поле ADMIN_KEY, если сессия уже активна; пароль не требуется и не сохраняется новым разделом.
- Состояние ошибки объясняет, что нужно открыть «Служебное».
- service-worker обновлён до R1310, чтобы очистился устаревший кэш.

Установка: загрузи ZIP через штатное обновление сайта как FULL, без удаления Cloudflare D1 и R2.
Проверка: https://control.andrikmetal.com/youtube-releases-admin.html
Ожидается «Защищённая сессия владельца подключена» и «Доступ подтверждён».
После восстановления авторизации нажми «Перечитать плейлисты YouTube».

Ограничения: это фикс авторизации, не обход ограничений YouTube Data API для Topic-каналов/OLAK плейлистов.
