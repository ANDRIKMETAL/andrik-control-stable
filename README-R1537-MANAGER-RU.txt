ANDRIK R1537 — MANAGER CPU DECISIONS

Полный ZIP сайта на базе R1535-SHA1-FIXED. Загрузить через «Обновить сайт».

- API GUARD теперь сохраняет проверенные cpuDiagnosis и systemLoad из R1536.
- MANAGER создаёт CPU задачу только при подтверждённой устойчивой нагрузке.
- transient-spike и insufficient-history не создают CPU задачу.
- При критической длительной нагрузке приоритет «Срочно»; при высокой — «Проверить».
- Сведения о нагрузке на ядро и статусе WATCH учитываются в рекомендациях.
- Принять, Отклонить, Выполнено, история и D1 сохраняются без миграций.
- Никаких команд на VPS и никаких автоматических перезапусков/удалений.
- Без дополнительных API и платных вызовов.

ВНИМАНИЕ: необходим установленный R1536 на VPS, чтобы передавать новые поля.
Контрольная сумма SHA-1 для полного ZIP должна быть рассчитана установщиком от фактических байтов файла, не от прежнего архива.
