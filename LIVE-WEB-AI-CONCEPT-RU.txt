LIVE WEB AI — КОНЦЕПЦИЯ ПРОДУКТА

Текущее состояние:
ANDRIK остаётся первым подключённым рабочим проектом.

Будущие универсальные модули («розетки»):
1. WEBSITE — подключение любого сайта, домена, служебных доступов, мониторинга и обновлений.
2. GOOGLE — подключение Google Analytics 4 и Google Search Console.
3. YOUTUBE — подключение YouTube Data API и YouTube Studio.

Принцип:
Пользователь один раз вводит данные подключения. После этого Live Web AI показывает аналитику, состояние служб, аудиторию, события, автоматизацию и уведомления.

Брендинг:
Название: Live Web AI
Иконка приложения: зелёный круглый глаз
ANDRIK: первый connected profile / демонстрационный рабочий проект.
