КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ META
Этот патч реализует автоматическое расписание отправки RTMPS сигнала на FB и автоматическую остановку своей ветки; он НЕ создает новую публикацию, НЕ вставляет заголовок/описание через Facebook API и НЕ нажимает Go Live на профессиональном профиле. Право publish_video на этом приложении Meta не подтверждено. Даже если RTMPS сигнал подан по расписанию, публичный LIVE может потребовать ручного подтверждения. Для полностью автоматической публикации с названием требуется разрешенный механизм Meta; его нет в этой версии.

Безопасность: присутствовавший на скриншотах user access token лучше заменить до настройки секрета Cloudflare.
Статистика: `views` = значение поля Meta Video.views, не "зашли" и не "смотрят сейчас". Прежний `total_video_views` возвращал другое значение; метрики не объединяются.
Если Meta ограничит или отключит эфир, система не обходит ограничения и не форсирует публикацию.
