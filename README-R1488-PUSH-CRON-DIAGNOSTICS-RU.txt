ИЗМЕНЕНИЯ
1. R768: регистрация owner-устройства теперь сразу подтверждается после записи в D1.
   Внешний тест OneSignal вынесен в Cloudflare waitUntil; результат записывается
   отдельно и читается через защищённый краткоживущий owner-token. UI не висит
   на 5/5 бесконечно, показывает разницу между "привязан" и "OneSignal принял тест".
   Принятие OneSignal НЕ гарантирует отображение в Android.
2. Добавлен лёгкий GET /api/control/cron-diagnostic-r1488 (защищён владельцем):
   реальные отметки heartbeat Cron, лайков/комментариев и проверки подписчиков.
   Никаких запросов к YouTube/OneSignal и запусков резервных копий.
3. В Служебном появилась кнопка "Проверить Cron безопасно".
   Старый "Запустить сейчас" переименован в "Полный запуск (нагрузка)" с
   подтверждением. Он по-прежнему способен вызвать HTTP 503 при перегрузке;
   ежедневную автоматизацию нужно запускать плановым внешним Cron.

ВАЖНО: ZIP не меняет Cloudflare Cron Trigger, secrets, привязки D1 или OneSignal.
Если Cron в Cloudflare не запланирован/запускается с ошибкой, одно обновление ZIP
не восстановит расписание. Проверь Workers & Pages -> [нужный Worker] -> Triggers.
Синхронизация новых подписчиков: YouTube скрывает персональные подписки;
числовой счётчик обновляется после очередной успешной проверки.

УСТАНОВКА: полный ZIP через контрольку. Перед этим сохраните работоспособную
версию R1487 и убедитесь, что текущий установщик поддерживает SHA-1 manifest.
После установки: Служебное -> "Проверить Cron безопасно"; затем при необходимости
"Подключить мой телефон". При ошибке не повторяйте полный запуск многократно.

4. Исправлена ссылка на привязку: query cache-busting теперь перед #owner=token,
   а не после фрагмента; для push-repair и service-admin задан no-store.
