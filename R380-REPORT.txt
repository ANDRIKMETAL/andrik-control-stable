R380 — CENTRAL COUNTRY ISO FIX: FLAGS + WORLD DOTS + DEEP COUNTRY MAP

Корень проблемы R379:
- список мог содержать русское/английское название страны вместо ISO-2;
- из-за этого countryFlag получал не код и показывал белый флаг;
- world marker fallback не мог надёжно определить страну;
- deep country map selectedCode не находил контур и большая карта страны не рисовалась.

Исправлено централизованно:
1. Добавлен resolveCountryIsoR380().
2. Индекс строится автоматически для всех ISO-кодов из карты сразу в двух языках:
   Intl.DisplayNames ru + en.
3. Добавлены алиасы США, Великобритания, ОАЭ, ЮАР, Южная Корея,
   Киргизия/Кыргызстан, Пуэрто-Рико и др.
4. renderWorldMap теперь сначала нормализует country/name -> ISO и только потом:
   - строит флаг;
   - ставит одну точку страны;
   - пишет data-code.
5. worldCountryGeo использует тот же resolveCountryIsoR380.
6. runtime экспортирует resolveCountryCode.
7. country-map-r352.js использует runtime.resolveCountryCode перед открытием
   большой карты страны.
8. Контуры IR, KG, PA, PR проверены — они реально присутствуют в country-shapes-r341.js.
9. Проверены 39 текущих названий стран из списка: все резолвятся в ISO.

Ожидаемый результат:
- Иран: 🇮🇷 + точка на мире + большой контур Ирана.
- Киргизия: 🇰🇬 + точка + большая карта.
- Панама: 🇵🇦 + точка + большая карта.
- Пуэрто-Рико: 🇵🇷 + точка + большая карта.
- Следующие новые страны автоматически получают ISO через ru/en Intl.DisplayNames.
