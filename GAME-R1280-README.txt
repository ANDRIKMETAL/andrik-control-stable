ANDRIK GAME — ПОРТРЕТ / R1280 BETA

Этот ZIP — ПОЛНЫЙ САЙТ, структура готова для привычной загрузки ZIP сайта.
Это не архив сервера вещания. На VPS радио устанавливать его не нужно.
Основой служит присланный SITE-R1279-FB-RETRY-GUARD.zip.

ПОРЯДОК 3D-МИРОВ:
1. City of Sleep
2. Ocean
3. ПОРТРЕТ
4. Star Runner
5. The Tower
6. Ruins of Epochs
7. Block Labyrinth — Тетрис последний.

УСТАНОВКА
1. Сохрани текущий ZIP сайта для отката.
2. Сначала проверь сборку на тестовой копии. В ней есть настоящая игровая
   механика, но полноценная браузерная и Android-приёмка не выполнена.
3. Загрузи ЭТОТ ZIP через обычное обновление сайта.
4. Открой https://andrikmetal.com/cache-reset.html — штатная очистка сайта.
5. Открой https://andrikmetal.com/dreaming-of-lira.html?v=R1280
6. В 3D-меню выбери «Миры» → «ПОРТРЕТ».

В существующем сохранении «Портрет» доступен после Ocean. Ранее открытые
миры сохраняются. При новой игре Star Runner открывается после «Портрета».
Классический режим 2D оставлен с исходными шестью мирами.

Если сайт после присланного R1279 уже менялся, не заливай полный старый снимок
поверх новой версии: перенеси только пять игровых файлов из списка ниже.
Их можно применить приложенным game-r1280-tools/install-game.py, который
проверяет совместимость, создаёт резервную копию и печатает команду отката.
У него есть --check и --root; без --root целевой сайт — текущий каталог.
Установщик не вызывает systemctl, FFmpeg или Node и не делает сетевых запросов.

Старый рендерер lira-3d-r1239.js уже оставлен в assets/. Новые четыре файла

УПРАВЛЕНИЕ
ПК: WASD/стрелки — движение; мышь после клика в сцену — камера;
Space — прыжок; Shift — рывок; ЛКМ — гитара; ПКМ — нога;
Q — крик; E — действие; Esc — пауза.
Без захвата мыши камера вращается перетаскиванием.
Телефон: левый джойстик, правая свободная зона для камеры, шесть кнопок действий.
Полное отклонение джойстика — бег. Поверни телефон горизонтально, нажми ⛶.

ПРОХОЖДЕНИЕ
Галерея: перепрыгивай лучи, победите трёх Масочников, E у голубой печати.
Арена: три волны врагов.
Зеркала: E возле каждого зеркала меняет угол на 45 градусов. Следи за лучом.
Победи двойника; нужны и победа, и правильный световой путь.
Башня: прыгай через разрывы. Красные платформы рушатся через 1,5 секунды.
У открытых ворот каждой зоны нажми E / «Действие».
Босс: атакуй открытый центр груди; крик во время замаха может прервать атаку.
После победы: финальная сцена, продолжение в Star Runner, повтор или меню.

ЗВУК
Громкость музыки и эффектов регулируется в паузе отдельно.
Можно выбрать инструментальную версию «Портрет» как локальный аудиофайл.
Он не отправляется на сервер; после перезагрузки страницы выбирается заново.
Новая глава не управляет радио или вещательными API.

ПРОВЕРКА ЛОКАЛЬНО
Распакуй этот ZIP, открой терминал в его корне и выполни:
 python3 -m http.server 8088
Открой http://localhost:8088/dreaming-of-lira.html
Локальный сервер нужен только для игры; серверные функции контрольки на нём
недоступны. Не открывай HTML через file://.

Чтобы проверить главу без прохождения первых двух миров, только на локальной
тестовой странице выполни в консоли браузера:
 localStorage.setItem('andrik-campaign-r1280',JSON.stringify({unlocked:[1,2,'portrait',3,4,6,5],completed:[],last:'portrait'}));location.reload();
