ANDRIK Control R324
Base: R323 / proven R315 admin carousel.

WAV speed changes:
- MP3 320 kbps encoding moved to a dedicated Web Worker, keeping the UI responsive.
- Native 32/44.1/48 kHz WAV rate is preserved, avoiding unnecessary 48 -> 44.1 kHz resampling.
- Queue progress no longer rebuilds the whole album DOM on every progress update.
- Progress UI is throttled to roughly twice per second.
- Encoder reuses PCM conversion buffers instead of allocating new Int16 arrays for every 1152-sample block.
- Original WAV reference is replaced by the resulting MP3 after successful upload, reducing retained memory.
- WAV read gets one short automatic retry on Android file-provider read errors.
- Compatibility fallback remains if Web Worker encoding is unavailable.

Retained:
- MP3/WAV editor first and open by default.
- Batch WAV processing one track at a time.
- MP3 320 kbps quality.
- R2 delete and bulk delete.
- Player compact MP3 download button.
- R315 carousel/admin shell unchanged.
