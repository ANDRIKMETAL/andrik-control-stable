ИСПРАВЛЕНИЯ
1. При исключении в много-видео проверке comments продолжает исполняться LIVE-чат.
   Раньше исключение прерывало всю задачу и LIVE-комментарии не проверялись.
   Проверки оставлены последовательными, чтобы не удвоить нагрузку API.
2. Падение внутри maintenance теперь передаётся в статус верхнего уровня.
   Ранее runCronMaintenanceSliceR416 мог вернуть ok:true + degraded:true + status:partial,
   а внешняя задача считала это успехом. Ошибки не маскируются.
3. На странице Служебное -> CRON DIAGNOSTICS по каждому заданию выводится
   причина последней ошибки (sweep, live, snapshots, nativeMonitor, websub, backup,
   checkpoint и др.), длительность и время завершения.
4. На странице Расписание и синхронизация отображаются те же причины.
5. В CRON DIAGNOSTICS показаны последние пять записей push подписчиков:
   тип, статус, время, количество получателей, наличие ID OneSignal, ошибка.
   Принятие OneSignal не гарантирует появления уведомления в Android.
6. Не менялись D1 таблицы/данные, Cron Trigger/секреты, радио, игра, графики,
   пользовательские настройки, существующая логика R1508 для прироста и отписок.
