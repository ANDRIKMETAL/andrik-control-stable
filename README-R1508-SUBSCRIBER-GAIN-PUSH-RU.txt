ANDRIK SITE R1508 — ИСПРАВЛЕНИЕ PUSH О НОВЫХ ПОДПИСЧИКАХ
Дата: 29 октября 2026
Основа: SITE-R1507-YOUTUBE-UNSUBSCRIBERS-FIX-FULL.zip

ЧТО ОБНАРУЖЕНО В КОДЕ R1507
В 15-минутном проверочном цикле при увеличении общего числа подписчиков
существовала логика visibleCreditR1203, которая могла целиком погасить
уведомление по изменению количества. Это происходило, когда ранее удалось
отправить отдельное сообщение о публичном подписчике. Но успешный ответ
OneSignal — это только принятие к доставке, а не гарантия показа в Android.
Из-за этого не обязательно формировался отдельный push о росте счётчика.

ИСПРАВЛЕНО
1. Рост общего числа теперь всегда формирует самостоятельный push о приросте
   (включая восстановление пропущенного прироста по watermark). Прежний
   visibleCredit не может подавлять этот push.
2. В том же опросе публичные профили не отправляются отдельно, если
   общий счётчик вырос; после принятия счётчикового push профили сохраняются
   как уже учтённые. Это убирает двойные уведомления одного опроса.
3. Если счётчик не изменился, обнаружение новых публичных подписчиков
   продолжает работать, как и раньше. Такие пуши могут опередить запаздывающий
   публичный счётчик YouTube; после его обновления придёт подтверждение прироста.
4. Механизм отписок R1507, очередь повторных отправок OneSignal R1505,
   отдельные уведомления R1506 и раздельные задачи Cron R1504 сохранены.
5. Не изменены таблицы D1, расписания Cron, secrets, OAuth, OneSignal,
   остальные файлы сайта, радио, графиков, игры.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Эта сборка исправляет выявленное подавление уведомлений в коде. По ZIP
  невозможно подтвердить, что на сервере сейчас выполняется Cron, что YouTube
  сообщил о приросте или что Android доставил уведомление.
- Проверка подписчиков в Split Cron каждые 15 минут; колебания между опросами
  могут компенсироваться. При 1000+ YouTube API округляет число подписчиков
  до трёх значащих цифр — единичный прирост может остаться незаметным.
- OneSignal подтверждает принятие запроса, а не факт показа в шторке Android.
- Старые пропущенные события не восстанавливаются автоматически, если текущий
  счётчик уже синхронизирован с сохранённой базой.

ПОСЛЕ УСТАНОВКИ
1. Установить ZIP штатным обновлением ANDRIK Control.
2. Служебное → CRON DIAGNOSTICS: подписчики ON, последняя попытка,
   статус, ошибка; Split Cron subscribers — закончился OK за последние 15–20 мин.
3. Если счётчик реально увеличился: в истории push искать
   type=youtube-subscriber-count, статус sent/failed; при sent смотреть
   доставку OneSignal и привязку устройства владельца.
4. При отсутствии опроса проверять URL /api/automation/cron-gateway?job=subscribers,
   Cron Trigger */15, секреты / привязку D1; без фактического доступа к
   Cloudflare эти условия не подтверждены.
