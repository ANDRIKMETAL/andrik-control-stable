ANDRIK SITE R1514 — ШЕСТОЙ АЛЬБОМ: РАДИО, ZIP И ОТДЕЛЬНЫЕ MP3

Основа: полный SITE R1513.

САЙТ
• Из «Релизов» удалён завершённый ZIP-загрузчик No One to Become.
• Загруженные ZIP и 12 MP3 остаются в R2.
• В альбоме видна кнопка «Скачать архив ZIP».
• Ниже — «Треки альбома · слушать / скачать», как у Silent: 12 аудиоплееров
  и отдельная кнопка MP3 у каждого трека. RU, UA, SK, EN.
• Список и ZIP-ссылка уже находятся в HTML. При задержке API они сохраняются.
• Обложка не растягивается при раскрытии длинного списка треков.

НАСТРОЙКИ РАДИО
• Добавлена карточка «6 · No One to Become».
• Для статики по умолчанию используется присланная обложка альбома.
• Можно отдельно загрузить JPG/PNG/WebP и отдельно MP4 до 16 секунд / 32 МБ.
• Переключатель изображения / видео и подготовка вперёд-назад работают
  через существующие настройки и API.
• Covers / Extended / Singles — седьмая карточка с прежним ключом extras.

УСТАНОВКА
Этот полный архив устанавливается через контрольку → «Обновить сайт».
Чтобы рабочий эфир на VPS распознавал шестой слот, нужен отдельный
ANDRIK-R1514.zip. Его файлы также лежат в radio247/r1514/ этого архива.
Патч изменяет установленный server.mjs точечно и сохраняет его существующие
исправления. Применение один раз перезапускает радио; возможен короткий перерыв.
Команды и проверка совместимости описаны в README-RU.txt внутри патча.
Полный исторический radio247/server.mjs не заменяет текущий файл на VPS.

ПРОВЕРКИ
Рабочий API подтвердил ZIP и 12 MP3. Все 12 MP3 вернули HTTP 200 и audio/mpeg;
ZIP вернул HTTP 200, правильное имя и размер 81 753 746 байт.
В браузере первый аудиоплеер загрузил трек без ошибки, длительность 4:17.
Проверены раскрытие списка, 12 кнопок MP3, мобильная ширина 375 px без
горизонтального переполнения, новая карточка радио, её обложка, поля статики
и MP4, отсутствие завершённого ZIP-загрузчика в «Релизах».
Настоящим кодом Worker в тестовом хранилище проверены статическая обложка,
независимые ключи изображения/видео, выбор шестого слота, Range для MP4,
сохранение настройки бегущей строки, защита записи и возврат к обложке.
Патчер VPS проверен на доступном серверном исходнике: определение владельца,
старые альбомы, Extras, подготовленные фоны, синтаксис и повторное применение.
Полный ZIP проверен кодом предварительной проверки и установщика сайта.

В этой среде новая версия сайта не опубликована и патч на рабочем VPS
не запускался. MP4 шестого альбома не предоставлен; добавлена возможность
его загрузки и выбора. Текущие данные R2 не менялись.
