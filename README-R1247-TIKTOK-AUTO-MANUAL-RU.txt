ANDRIK R1247 — TIKTOK AUTO MANUAL-ONLY

Исправлено:
- переключатель AUTO START / STOP больше не включён по умолчанию в интерфейсе;
- выбор пресета 8 / 10 / 12 часов больше НЕ включает AUTO автоматически;
- AUTO включается только явным ручным нажатием владельца и сохранением расписания;
- существующий серверный статус по-прежнему отображается честно: если OVH реально хранит enabled=true, интерфейс покажет ON, поэтому для полного исправления нужен серверный патч R1307 DEFAULT-OFF.
