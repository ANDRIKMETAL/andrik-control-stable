ANDRIK R1531 — GUARD

GUARD снимает показатели каждые 2 минуты. В контрольке видны заполнение диска,
RAM, загрузка CPU, состояние служб, процессы FFmpeg и временные файлы старше
24 часов. Если кэш радио на отдельном диске, его заполнение тоже показывается.
CPU измеряется за 0,8 секунды. Предупреждение для диска и RAM начинается с 85%,
для CPU — с 90%. Отчёт считается устаревшим через 5 минут.

GUARD проверяет выход радио через штатный /status на самом VPS. Для проверки
доступности трансляции зрителям нужен следующий этап WATCH.
Для временных файлов GUARD просматривает кэш радио и файлы andrik-* в /tmp
и /var/tmp. При достижении лимита обхода или недостатке прав помечает проверку
как частичную. В отчёт попадают только количество и общий размер файлов.

Нужен действующий Ubuntu VPS с Python 3 и systemd. Отчёт отправляется по HTTPS
на andrikmetal.com. Контролька хранит один последний замер в своей
текущей базе D1. При интервале 2 минуты это около 720 записей в сутки в одну
строку. Для работы не требуются OpenAI API, дополнительная база или платные
интеграции. GUARD читает состояние VPS и публикует отчёт. Служба радио и её
агент не перезапускаются, файлы кэша не удаляются.

Установка

1. Загрузить SITE-R1531-GUARD.zip в «Обновление» контрольки, указать R1531
   и дождаться завершения Deploy. Это полный ZIP сайта на основе R1530.
2. В контрольке открыть «AI Агенты» → «Подключение VPS», скопировать команды
   установки и выполнить их в Bash на VPS.

   mkdir -p "$HOME/andrik-guard-r1531" &&
   cd "$HOME/andrik-guard-r1531" &&
   curl -fsS --fail-early --remote-name-all https://andrikmetal.com/radio247/guard-r1531/{INSTALL.sh,guard.py,andrik-guard-r1531.service,andrik-guard-r1531.timer} &&
   sudo bash INSTALL.sh --apply

   Можно также передать ZIP на VPS и запустить установщик из корня архива.

   sudo bash radio247/guard-r1531/INSTALL.sh --apply

   Команды для ZIP в домашней папке VPS приведены ниже.

   unzip -o "$HOME/SITE-R1531-GUARD.zip" -d "$HOME/andrik-r1531"
   sudo bash "$HOME/andrik-r1531/radio247/guard-r1531/INSTALL.sh" --apply

3. В контрольке открыть «AI Агенты» → «Подключение VPS» → «Получить код».
   Вставить код в терминал, когда установщик его попросит, и нажать Enter.
   При вставке код не отображается. Он одноразовый и действует 10 минут.
4. После сообщения «GUARD подключён» нажать «Обновить» в карточке GUARD.
   Для разбора в ChatGPT открыть «Отчёт для ChatGPT», нажать «Подставить замер»
   и «Скопировать запрос».

Диагностика

Команда для локальной проверки показателей из корня распакованного архива.

   bash radio247/guard-r1531/INSTALL.sh --check

Команды для проверки состояния таймера и журнала работы.

   systemctl list-timers andrik-guard-r1531.timer --all --no-pager
   sudo journalctl -u andrik-guard-r1531.service -n 25 --no-pager

При утрате ключа получить новый одноразовый код и повторить --apply. После
использования нового кода старый ключ GUARD перестаёт приниматься.
Следующая команда останавливает GUARD и выключает его автозапуск.

   sudo bash radio247/guard-r1531/INSTALL.sh --disable

Кнопки, шапка «Управление проектом» и вращающаяся планета на главной
контрольки взяты из R1530. WATCH, MANAGER и MUSIC обозначены как следующие
этапы.
