ANDRIK R1514 — ШЕСТОЙ АЛЬБОМ В ФОНАХ РАДИО

Это точечный патч установленного server.mjs, а не полная замена старой копией.
Добавляет no-one-to-become в списки альбомов, шаблоны подготовленных фонов,
определение владельца трека и состояние /status. Существующие исправления
передачи, аудио, CPU и подготовки вперёд-назад сохраняются в исходнике.

Требуется существующая поддержка видеоальбомов R1473 или новее.

После распаковки на VPS:
  sudo bash INSTALL.sh --check
  sudo bash INSTALL.sh --apply

Первый запуск проверяет текущий файл и синтаксис, не меняя его.
Второй делает резервную копию и один раз перезапускает andrik-radio.service.
Возможен краткий перерыв эфира. При неподтверждённом запуске возвращается
исходный server.mjs. Если исходник отличается по структуре, изменения не вносятся.

Сначала установи SITE-R1514. В контрольке «Видео эфира» появится
«6 · No One to Become». Для статики доступна обложка альбома с сайта;
для видео выбери MP4 в этой карточке и затем «Видео ↔ вперёд-назад».
Настройка остальных альбомов и слота Covers / Extended / Singles сохраняется.

Патчер проверен на доступных серверных исходниках: расширение списков,
определение альбома, проверка JavaScript и повторный запуск без изменений.
На рабочем VPS в этой среде не запускался.
