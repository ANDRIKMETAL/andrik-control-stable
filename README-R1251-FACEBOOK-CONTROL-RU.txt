ANDRIK SITE R1251 · FACEBOOK CONTROL

- Убрана отдельная карточка Facebook с главной админ-панели.
- Facebook остаётся внутри раздела Радио.
- RTMPS YouTube в Facebook-панели ограничен реальными 2/2.
- Добавлены: исходящий Mbps, uptime, 7h countdown, rotate/restart counters,
  график Facebook telemetry и последние события.
- START/STOP остаются изолированными от YouTube/TikTok.
- Число зрителей Facebook не берётся из RTMP: для него нужен Meta Insights/Graph access.
- Серверная авто-ротация реализована в RADIO R1316.
