ANDRIK SITE R1510 — CRON / PUSH STABILITY
Дата: 29 октября 2026. Основа: R1509.

Исправления по реальному PUSH/YOUTUBE DIAGNOSTIC LOG R526:
1. Comments LIVE: отсутствие необязательного поля YouTube concurrentViewers
   больше не превращает успешную проверку комментариев и чата в FAILED.
   Важные сбои, сетевые ошибки и отказы доставки по-прежнему приводят к FAILED.
   Предупреждение о метрике видно отдельно в metricWarningsR1510.
2. Maintenance: проверка Facebook Metrics пропускается, когда Facebook
   выключен (HARD OFF либо нет запущенного/включённого вещания и расписания).
   Просроченный Facebook Access Token больше не ломает обслуживание радио/сайта
   при выключенном Facebook. Для активного Facebook ошибка токена остаётся
   реальной ошибкой, токен требуется обновить через Meta.
3. Новые страны: если OneSignal недоступен и создана отложенная попытка,
   очередной цикл не начинает повторную немедленную отправку того же события.
   После успешного восстановления очередь фиксирует отправленную страну.
4. Не изменены настройки владельца, Google/YouTube API, база D1 (нет миграций),
   радио/VPS, игра, остальные уведомления, cron интервалы, ограничения и секреты.

ВАЖНО: OneSignal successful=1 и received=0 означают подтверждение со стороны
платформы, но не факт показа уведомления в Android. Устранение причин
отсутствия уведомлений на телефоне требует проверки настроек Android,
активности подписки OneSignal и фактического появления тестового PUSH.

Проверки: синтаксис JS, расчёт SHA git blob для файлов, проверка архива.
