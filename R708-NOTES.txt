R708 — OVH AGENT ESM + MORNING PULL FIX

ROOT CAUSE FIXED
- R707 installed an ES-module source into extensionless /usr/local/sbin/andrik-radio-web and launched it with `node`.
- Node 18 parsed the extensionless file as CommonJS and failed with: Cannot use import statement outside a module.
- The new morning slot therefore never reached the running OVH agent; Control kept talking to the old agent and returned «Неверный visual slot».

R708
- Installs the agent only as /usr/local/lib/andrik-radio-web-agent-r708.mjs.
- /usr/local/sbin/andrik-radio-web is now a tiny shell wrapper that executes the .mjs file.
- systemd unit is overwritten unconditionally to use the wrapper.
- Installer verifies agent is active and rejects the old ESM SyntaxError.
- Pulls the already-uploaded MORNING R2 master to OVH, then restores AUTO schedule.
- R707 exact title/PCM synchronization preserved.
- R706 true-motion EQ preserved.
- R702 MP3/clip handoff preserved.
- AUTO FIT / NO CROP preserved.
