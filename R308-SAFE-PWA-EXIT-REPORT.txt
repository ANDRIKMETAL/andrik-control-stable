ANDRIK Control R308 — SAFE PWA EXIT
Date: 07.08.2026
Base: R307 (which already contains R305 map/summary and R302 background push work)

Changed only exit behavior + displayed build version:
- Removed the R307 fake black "Control закрыт" fallback from active exit logic.
- Removed any public-site redirect/history-unwind fallback from active exit logic.
- "Выйти" now only attempts close methods that Android/WebView/PWA may support.
- If Android refuses programmatic close, Control remains intact and shows a short hint: "Для полного выхода нажмите Домой".
- "Остаться" still closes the confirmation dialog normally.
- Same safe behavior on the main Control page and Statistics/map page.
- Added R308 cache-reset page and version synchronizer.

NOT CHANGED:
- map geometry / country focus
- bottom buttons
- daily summary / Google Analytics refresh
- YouTube / comments / push / Cron / Guard
- updater logic

Web/PWA limitation:
A standard installed PWA cannot be guaranteed to terminate its Android task from JavaScript.
R308 therefore avoids pretending the app is closed and avoids navigating the user elsewhere.
