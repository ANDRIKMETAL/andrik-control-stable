🚑 Как восстанавливается

Основная золотая точка — FINAL DR. SHA256 проверяет целостность. RESTORE.sh безопасно возвращает ANDRIK, systemd, env и fullscreen-настройки. BOOTSTRAP предназначен для новой Ubuntu 24.04: ставит зависимости, забирает комплект из R2, проверяет его и запускает безопасное восстановление.

🔒 Активной кнопки «ВОССТАНОВИТЬ СЕЙЧАС» здесь нет намеренно. Восстановление запускается только на целевой Ubuntu через BOOTSTRAP/RESTORE. Так страница остаётся контрольным центром и не может случайно перезаписать работающий эфир.

TRANSFER оставлен как отдельная историческая страховка для миграции.
