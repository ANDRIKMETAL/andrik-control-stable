ANDRIK SITE R1492 — CRON GATEWAY LATENCY GUARD

Основа: полный SITE R1491. Изменён только _worker.js и манифест.

Изменение: когда совпадают 2-минутная проверка лайков/подписчиков и
5-минутная проверка комментариев, дополнительная проверка комментариев
выполняется в Cloudflare waitUntil, а не блокирует HTTP-ответ Cron Gateway.
Сохранены дедупликация задания, уведомления, расписание и диагностика.
Ошибки этой фоновой проверки записываются в push_state по ключу
cron-r1492-comments-overlap-error.

Важно: это точечная гипотеза по задержке gateway, НЕ доказанное
исправление всех ошибок. Центральный Worker и его расписание не меняются.
Другие длительные проверки в Cron Gateway могут по-прежнему задерживать
ответ. CPU warnings Cloudflare могут относиться к другому Worker.

Установка: обычный установщик полного ZIP в контрольке.
Радио, 3D-игра, интерфейс и база данных не меняются.
