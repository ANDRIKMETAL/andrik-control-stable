SITE R1444 — единый прогресс установки и релиз SILENT

Полный сайт на основе облегчённой сборки R1443. Функции контрольки R1442
для бегущей строки и альбомных видео сохранены.

ОБНОВЛЕНИЕ САЙТА
Вместо шести отдельных ячеек — одна полоса с процентами внутри,
название текущего этапа и короткое пояснение.
Проценты показывают завершённые этапы, а не время или долю переданных байтов:
0 → 17 → 33 → 50 → 67 → 83 → 100%.
Во время ожидания публикации проценты остаются на подтверждённом значении.
100% появляется после итоговой проверки либо подтверждения отсутствия изменений.
Незавершённая проверка не выдаётся за успешную установку.

Единые цвета полосы, статуса процесса и шапки:
— серый: процесс ещё не начат;
— голубой: проверка архива, готовность к установке или выполнение этапа;
— жёлтый: ожидание публикации, восстановление или предупреждение;
— зелёный: успешное завершение;
— красный: явно подтверждённая ошибка этапа или результата.

Убраны поиск ошибок по словам в обычном тексте и отдельная смена цвета
для каждого номера этапа. Старые сообщения не перекрашивают новую установку.
Шесть внутренних состояний сохранены для действующей логики установщика,
но их старые ячейки больше не отображаются.
