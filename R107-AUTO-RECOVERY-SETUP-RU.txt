R107 — УСТАНОВКА ЧЕРЕЗ CONTROL

1. Сначала заверши проверку R106.
2. Control → Служебное → Обновить сайт.
3. Выбери полный архив R107.
4. Нажми ОБНОВИТЬ САЙТ.
5. Дождись завершения этапов ZIP → Backup → Commit → Release → Сайт.
6. После публикации открой:
   /cache-reset-v55-00-final-r107.html
7. В R107 появится шестой этап «Защита» и переключатель автоматического отката.

Автозащита R107 применяется к следующим публикациям, сделанным через R107.
Ручная раскладка по GitHub не требуется.
