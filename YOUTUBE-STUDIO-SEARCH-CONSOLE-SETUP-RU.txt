YOUTUBE STUDIO — ПОЛНАЯ СТАТИСТИКА

В Cloudflare Pages → проект andrikmetal → Settings → Variables and Secrets должны существовать:
YOUTUBE_OAUTH_CLIENT_ID
YOUTUBE_OAUTH_CLIENT_SECRET
ADMIN_KEY
COMMENTS_ADMIN_KEY (оставить для совместимости со старым зашифрованным токеном)
CRON_SECRET

В Google Cloud OAuth Client типа Web application должны быть указаны:
Authorized JavaScript origin:
https://andrikmetal.com

Authorized redirect URI — ровно:
https://andrikmetal.com/oauth/youtube/callback

Порядок после загрузки сборки:
1. Откройте Control → Служебное.
2. Убедитесь, что ADMIN_KEY принят.
3. В карточке YouTube Studio OAuth нажмите «Подключить YouTube Studio».
4. Выберите аккаунт владельца канала и разрешите доступ.
5. После возврата Control сам проверит реальный серверный refresh token и обновит снимки Studio.
6. На экране YouTube должны появиться графики, возраст, пол, площадки и недельная статистика стран — если YouTube уже накопил соответствующие данные.

Вручную вводить refresh token или API-ключ в Control не нужно.
Кнопка запускает безопасный Google OAuth; refresh token сохраняется сервером в зашифрованном виде в D1.

Если Google пишет, что приложение не прошло проверку:
Google Cloud Console → Google Auth Platform → Audience → Test users → добавить аккаунт владельца канала.

GOOGLE SEARCH CONSOLE

Control повторно использует service account Google Analytics. В Cloudflare должны существовать:
GOOGLE_ANALYTICS_CREDENTIALS
GOOGLE_ANALYTICS_PROPERTY_ID

Также может использоваться отдельный GOOGLE_SEARCH_CONSOLE_CREDENTIALS, если он уже настроен.

Нужно один раз выдать service account доступ к Search Console:
1. Откройте Google Search Console для ресурса sc-domain:andrikmetal.com.
2. Настройки → Пользователи и разрешения → Добавить пользователя.
3. В JSON GOOGLE_ANALYTICS_CREDENTIALS найдите поле client_email.
4. Добавьте именно этот email как пользователя ресурса.
5. В Google Cloud включите Google Search Console API для того же проекта.
6. Снова откройте экран Google Analytics в Control. v54.72 выполнит отдельную неблокирующую проверку Search Console и сохранит свежий снимок.

По умолчанию используется ресурс:
sc-domain:andrikmetal.com

ДОСТУП ВЛАДЕЛЬЦА — ADMIN_KEY

1. Cloudflare Pages → проект andrikmetal → Settings → Variables and Secrets.
2. Secret ADMIN_KEY уже должен содержать ваш сохранённый ключ.
3. Откройте Control → Служебное → Доступ владельца.
4. Введите то же значение и нажмите «Проверить и сохранить».
5. Старый COMMENTS_ADMIN_KEY также принимается для совместимости.
6. Не удаляйте COMMENTS_ADMIN_KEY, пока не будет подтверждено новое подключение YouTube Studio: старый OAuth refresh token мог быть зашифрован с его участием.
