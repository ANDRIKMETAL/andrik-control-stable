R338 — COUNTRY DRILLDOWN MAP

Что сделано:
1. Добавлен новый режим drill-down внутри выбранной страны на аналитической карте.
2. При выборе страны теперь появляется отдельная панель:
   - хлебные крошки «Мир › Страна»;
   - отдельная внутренняя карта активности по городам/регионам;
   - отдельный список городов/регионов по активности;
   - подписи вверху, что именно показывает карта и что показывает список.
3. Режим работает отдельно для активного слоя карты:
   - Вся экосистема
   - Сайт
   - YouTube
   - Music
   - Push
4. Для YouTube честно показывается сообщение, что в текущем API городская детализация недоступна, если нет точек уровня города.
5. Добавлена кнопка «← Мир» для быстрого выхода обратно из режима страны.
6. Обновлён номер текущей рабочей версии на R338 в основных страницах Control.

Важно:
- Геометрия основной мировой карты не ломалась.
- Детальная внутренняя карта строится по реально накопленным точкам latitude/longitude.
- Если по слою ещё нет детальных точек, показывается понятное сообщение без ошибок.
