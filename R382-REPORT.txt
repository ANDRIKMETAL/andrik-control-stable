R382 — REMEMBER LAST ECOSYSTEM MAP LAYER

Изменено:
- Последний выбранный слой главной карты сохраняется в localStorage.
- Поддерживаются: Вся экосистема, Сайт, YouTube, Музыка, Push.
- Если закрыть/уйти со Статистики на слое YouTube, следующий вход откроет мировую карту YouTube.
- Если закрыть на Сайте/Музыке/Push — восстановится соответствующий слой.
- При повторном открытии страна не сохраняется: всегда открывается общая карта мира, но на последнем слое.
- Для первой установки без сохранённого значения остаётся прежний безопасный default: Вся экосистема.
- Добавлено сохранение при pagehide/visibilitychange для Android/PWA/back navigation.

Сохранено:
- R381 прямой тап по стране из «Все страны» → карта страны.
- R380 централизованный ISO/флаги/точки/контуры стран.
- R378 одна страновая точка на общей карте.
- R377 быстрый плавный step-2 переход.
- R376 надёжные YouTube лайк/комментарий push.
