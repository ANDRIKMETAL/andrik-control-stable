ПОЧЕМУ
25 октября 2026 диагностика показывала: heartbeat 1 мин, реакции 1 мин,
подписчики 115 мин, последний завершённый gateway 115 мин, более 90 ошибок Cloudflare.
Это не подтверждает причин всех ошибок; для доказательства нужны записи конкретных
Cloudflare Events от andrik-central-cron-r461 с полями exceptionName/exceptionMessage.

ИСПРАВЛЕНИЯ
1) При центральном триггере */2 минуты слот :00/:10/:20/:30/:40/:50 выделен
   только подписчикам. Прочие 2-минутные слоты выделены лайкам/комментариям.
   Тем самым длинные реакции больше не блокируют запуск проверки подписчиков;
   дорогие цепочки не складываются в один синхронный ответ.
2) Дополнительная проверка комментариев запускается в фоне в :04/:14/... вместо
   пикового совпадения с подписчиками. Защита от повторных запусков сохранена.
3) Последняя попытка проверки подписчиков записывается отдельно от последнего
   УСПЕШНОГО опроса, вместе с кратким статусом/ошибкой. Новых таблиц нет.
4) Диагностика теперь сравнивает время последнего завершённого Gateway с heartbeat
   и сигнализирует, когда heartbeat свежий, а завершения запросов отсутствуют.
   Отчёт R1503 отображает ошибку/время попытки подписчиков.
5) Для страницы Служебное обновлён cache-busting JS.

ВАЖНО
- Это снижение нагрузки и восстановление независимого расписания подписчиков,
  а не доказанное устранение ошибок ЦЕНТРАЛЬНОГО Worker. Его исходников в ZIP нет.
- Cloudflare Cron Trigger, secrets, D1, сервис YouTube, OneSignal и VPS не меняются.
- Первая успешная отметка подписчиков должна появиться в течение ближайших
  10–12 минут после установки при живом Cron и рабочих YouTube credentials.
- Если есть ошибки CPU_TIME_LIMIT / Memory или Fetch Timeout в central-cron,
  их нужно устранять в самом andrik-central-cron-r461 по конкретному Event.
- При OAuth/YouTube API error диагностическое поле «Ошибка подписчиков» покажет
  её, если запуск успел завершиться и записать статус.
- Участки радио, игры, музыкальные файлы и D1 данные не сбрасываются.
- Архив не установлен на работающем сайте автоматически.

ПРОВЕРКА
Node syntax --check, SHA1 manifest consistency, архив CRC. Результат настоящего

первый шаг, сохраните лог установщика, не делайте многократных повторов.
