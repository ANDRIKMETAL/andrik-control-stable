ANDRIK · R1482 · НОВЫЕ РЕЛИЗЫ YOUTUBE + БЛОК «НОВОЕ»

Основа: полный SITE-R1481.zip, присланный владельцем.

ЧТО НАЙДЕНО
1. /api/public/youtube-latest возвращал сохранённый эфир, обновлённый
   20.10.2026, и не перепроверял его, пока запись существовала.
2. В быстром обработчике карточка обновлялась только после успешного push.
   Пропуск или ошибка отправки оставляли старое видео на главной.
3. Резервный поиск загрузок ограничивался интервалом около 30 минут.
   Ветки Cron и резервного контроля могли заниматься реакциями и сводками,
   не вызывая проверку релизов.
4. В первичном заполнении каталога была ссылка на несуществующие переменные
   identity/currentVisibleSubscribersR677, из-за чего первый запуск падал.

ЧТО ИСПРАВЛЕНО
— Независимое обнаружение загрузок и обновление карточки «Последнее на YouTube».
— Общая серверная выборка для сайта и Cron: повторные запросы используют
  сохранённый результат в течение 5 минут, не опрашивая YouTube заново.
— Отдельная проверка релизов в Cron и существующем резервном контроле,
  включая конфигурацию с одним двухминутным триггером.
— Резерв RSS при недоступности YouTube Data API.
— Эфир 24/7, приватное и будущее видео не заменяют карточку релиза.
— Старый callback не перезаписывает более новое видео; конкурентные записи
  защищены сравнением текущего значения в базе.
— Ошибка отправки не блокирует карточку и освобождает попытку для повтора.
— Уже известный каталог не рассылается заново при первичной синхронизации.
— Главная перепроверяет карточку без ручной перезагрузки; фоновые вкладки
  и невидимый блок не поддерживают постоянный опрос.
— Новый файл home-r1482.js подключён в RU/EN/SK/UK, версия кеша обновлена.

УСТАНОВКА
Контролька → «Обновить сайт» → выбрать SITE-R1482.zip → «Обновить сайт».
Дождаться успешной публикации Cloudflare. Обновить главную и контрольку.
Первая загрузка блока «Последнее на YouTube» запускает обнаружение видео;
уведомления подхватываются следующим циклом Cron/резервного контроля.
При работающих внешних сервисах интервал проверки составляет примерно 5–6 минут.

Если требуется проверить пропущенный ролик сразу:
Сервис → «Диагностика YouTube» → «Проверить безопасно».
«Запустить боевую проверку» запускает обычный поиск новых видео.
«Повторить push последнего видео» является явной повторной отправкой,
поэтому использовать её следует только если нужна повторная рассылка.

КАКОЙ БЛОК ОБНОВЛЯЕТСЯ
