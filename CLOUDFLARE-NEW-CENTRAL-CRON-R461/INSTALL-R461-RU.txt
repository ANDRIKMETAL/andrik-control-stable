ANDRIK CENTRAL CRON R461 — НОВЫЙ WORKER, СТАРЫЙ НЕ РЕДАКТИРУЕМ

Цель:
Создать новый Cloudflare Worker рядом со старым andrik-push-cron. Старый код не менять.

Имя нового Worker:
andrik-central-cron-r461

Код:
ANDRIK-CENTRAL-CRON-R461.js

Обязательно:
1. В новом Worker создать Secret с именем CRON_SECRET.
2. Значение CRON_SECRET должно быть ТО ЖЕ, которое уже использует Control. Сам секрет в файл не вставлять.
3. Добавить ровно три Cron Trigger:
   */2 * * * *
   */5 * * * *
   */15 * * * *
4. Другие переменные новому Worker не нужны.
5. После Deploy открыть адрес нового Worker + /health. Должно быть ok:true, version:R461.
6. Подождать 2–5 минут и в Control проверить Центральный Cron: heartbeat должен стать свежим.
7. Только ПОСЛЕ проверки отключить Cron Trigger у старого andrik-push-cron. Сам старый Worker можно оставить как резерв.

Важно:
- новый Worker вызывает современный /api/automation/summary-checkpoint и /api/automation/cron-gateway;
- расписание передаётся в Control, поэтому */2 и */5 больше не являются Unsupported cron;
- Guard, D1, сайт, карта, Push и YouTube код сайта не меняются;
- R461 сайта = R460 warning-cleanup + новый комплект для отдельного Cron Worker.
