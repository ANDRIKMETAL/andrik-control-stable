R108 — УСТАНОВКА

1. Проверить R107.
2. В Control открыть плавающую кнопку/раздел «Обновить сайт».
3. Выбрать полный ZIP R108 и нажать «ОБНОВИТЬ САЙТ».
4. Дождаться Backup → Commit → Release → Cloudflare → Защита.
5. Для установки самой R108 один раз открыть:
   /cache-reset-v55-00-final-r108.html
6. После R108 следующие обновления сами очищают локальный кэш после успешного Deploy.

Проверка push после установки:
Служебное → Центральный Cron → Запустить сейчас.
В журнале YouTube будут отдельные значения commentsSent/commentsFailed/commentsQueued.
