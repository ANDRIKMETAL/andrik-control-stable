ANDRIK R1029 · MEDIA REMOVE + REAL VIDEO PREVIEW

РАДИО / УДАЛИТЬ ИЗ ЭФИРА
- Поиск теперь одновременно видит MP3-треки и обычные MP4-клипы активной радио-библиотеки.
- Кнопка «УБРАТЬ ИЗ ЭФИРА» больше не вызывает VPS local-control track-remove, поэтому ошибка «TRACK REMOVE / unknown local control» устранена.
- Исключение хранится в Cloudflare R2 как служебный JSON и фильтруется прямо в API радио-библиотеки.
- MP3/MP4 остаётся в R2 и на сайте; удаляется только из будущей радио-ротации.
- Текущий файл доигрывает. Радио перечитывает библиотеку максимум примерно раз в 120 секунд.
- Служебные bumper 1/2/3 и special 30/60 защищены от случайного удаления через этот поиск.
- Повторная загрузка того же ключа после исключения автоматически делает файл активным снова.

R2 ХРАНИЛИЩЕ
- Для MP3 остаётся аудио-предпросмотр.
- Для MP4 теперь открывается настоящий video preview: видна картинка и слышен звук.
- Нажатие на строку файла запускает предпросмотр; эфир радио не затрагивается.

АРХИТЕКТУРА
- Изменения работают на Cloudflare Pages/Worker стороне. Отдельный VPS patch и рестарт радио для этой функции не нужны.
