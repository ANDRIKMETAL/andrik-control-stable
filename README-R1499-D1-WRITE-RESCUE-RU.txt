R1499 D1 WRITE RESCUE — базовая версия R1498.
Убраны записи D1 до и после каждого этапа диагностики.
Сводка диагностики сохраняется максимум раз в ~30 минут при штатной работе, плюс при исключениях.
Сохранены ограничения 4 видео за двухминутный цикл, штатные уведомления и галочки.
Не меняет центральный Cron, радио или игру.
ВНИМАНИЕ: это устраняет только диагностические записи, не гарантирует решение всего дневного лимита D1.
