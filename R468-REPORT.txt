R468 — LIVE YOUTUBE 06:05 DAILY COUNTERS SAFE FULL

Base: production R467 (which already includes the deployed R466 installer backup hotfix).

Changed only the active/today YouTube summary path and release labels:
1. Completed/archive dates keep R467 exact YouTube Analytics day values.
2. Active "today" YouTube likes are now cumulative channel likesTotal minus the snapshot nearest to 06:05 Bratislava.
3. Active "today" YouTube views are now cumulative channel viewCount minus the same 06:05 rollover snapshot.
4. Push like-event counts and stored daily-summary push metrics no longer define or inflate the YouTube likes card.
5. An old push/high-water value (for example 69 likes) can no longer override the authoritative live YouTube counters.
6. Fast R395 and atomic R405 response paths explicitly prefer the fresh accumulator YouTube values over an older push snapshot.
7. Fallback collection no longer fabricates YouTube likes from notification history.
8. A rollover snapshot must be within 90 minutes of 06:05 to be used as the live baseline; otherwise the safe old fallback remains.
9. R466 installer backup hang guard is preserved.
10. CENTRAL_CRON_SECRET_R462, Cron triggers, maps, music, subscriptions, D1 schema, player and monitoring are unchanged.

Semantics:
- Archive: exact YouTube Analytics calendar-day row when available.
- Today: live cumulative change since the 06:05 daily rollover baseline.
