ANDRIK R503 — TIKTOK SANDBOX / PRODUCTION SWITCH
=================================================
Base: R502 TikTok OAuth + Display API
Release: R503
Runtime: 55.00-r503

WHAT CHANGED
- Added explicit SANDBOX / PRODUCTION selector in Social Center TikTok card.
- Selected TikTok mode is remembered in localStorage.
- OAuth start sends the selected environment.
- OAuth state is HMAC-signed and carries the selected environment to the callback.
- Callback selects the matching Client Key + Client Secret only after state verification.
- Sandbox and Production OAuth tokens are stored in separate D1 rows.
- Token encryption keys are environment-specific.
- Sandbox and Production analytics snapshots are stored separately:
    tiktok-sandbox
    tiktok-production
- Social Center reads only the selected environment's snapshot/history.
- Hourly snapshot job collects each connected environment independently.
- No fabricated TikTok geography was added.

CLOUDFLARE VARIABLES
Production (existing):
  TIKTOK_CLIENT_KEY
  TIKTOK_CLIENT_SECRET       [Secret]
  TIKTOK_REDIRECT_URI        https://andrikmetal.com/api/oauth/tiktok/callback
  TIKTOK_SCOPES              user.info.basic,user.info.stats,video.list

Sandbox (new):
  TIKTOK_SANDBOX_CLIENT_KEY
  TIKTOK_SANDBOX_CLIENT_SECRET  [Secret]

Optional Sandbox overrides (NOT required when same as Production):
  TIKTOK_SANDBOX_REDIRECT_URI
  TIKTOK_SANDBOX_SCOPES

IMPORTANT
- Do not overwrite Production credentials with Sandbox credentials.
- TikTok Sandbox configuration must contain the same registered redirect URI.
- Add @andrikmetal as a Sandbox Target User before testing Login Kit.
