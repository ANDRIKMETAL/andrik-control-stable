ANDRIK SITE R1510 — ТИХАЯ КВОТА YOUTUBE API
Дата: 2 ноября 2026
Основа: SITE-R1509-CRON-COMMENTS-MAINTENANCE-PUSH-FULL-1.zip

ПРОБЛЕМА
Каждое утро владельцу приходит OneSignal push «⚠️ YouTube API — 50% основной квоты»
на 5000 из 10000 units. Причина — функция maybeSendYoutubeQuota50AlertR333:
порог 50% + уникальный ключ отправки на каждый тихоокеанский день.
При этом счётчик собственный, приблизительный, не подтверждает реальное исчерпание Google Cloud.

ИСПРАВЛЕНО
1) Убраны абсолютно все автоматические push об обычных 50% потребления YouTube Data API.
2) Приблизительный учёт quota в D1 и панель Observability сохранены без изменений.
3) По умолчанию только КРИТИЧЕСКОЕ предупреждение при >=95% расчётной квоты
   (никогда ниже 95%), строго максимум один раз за сутки по America/Los_Angeles.
4) При ошибке доставки ключ резерва снимается для повторной попытки.
5) Для полного отключения уведомлений о квоте можно задать Worker env:
   YOUTUBE_QUOTA_CRITICAL_PUSH=false
6) Если нужен другой критический порог от 95 до 100%:
   YOUTUBE_QUOTA_CRITICAL_PERCENT=98
   Меньшие значения намеренно поднимаются до 95%, чтобы не вернуть спам.

ЧТО НЕ МЕНЯЛОСЬ
- Сбор статистики, API-ключи, задачи cron, push о действительно новых событиях.
- Сообщения от YouTube, подписчиков, лайков, комментариев, радио, VPS.
- Не добавлены новые таблицы D1 и миграции.

ВАЖНО
Это архив для развёртывания, а не изменение работающего сайта автоматически.
До загрузки R1510 на Cloudflare ежедневные уведомления версии R1509 продолжатся.
Отдельный `50%` push, уже высланный до установки, из истории Android не исчезнет.
Счётчик квоты приблизительный; сравнивайте с фактическими показателями Google Cloud Console.
