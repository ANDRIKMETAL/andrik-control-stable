ANDRIK SITE R1278 FACEBOOK TCP METRICS · только контролька
База: R1277-FB-CONTROL-FIX, остальные файлы сайта сохранены.

Причина: на GOLD сервере Facebook работает через независимый UDP R1356/R1405.
В таком режиме счетчики R1314 в server.mjs равны 0 по архитектуре.
Нельзя вычислять реальную скорость по неиспользуемому inputBytes.

Изменено в radio-facebook-admin.html:
- TCP-скорость и история от дополнительного веб-агента (facebookTcpEgressR1278).
- При отсутствии реальных измерений показывается «—», а не фиктивное 0.0.
- Счетчик «ОТПРАВЛЕНО МБ» по TCP bytes_acked, при потере сигнала показывает «—».
- Убран старый блок ротации ещё в базе R1277.
- «RESTART» означает реальный restartCount, не ротации.

Для реальных графиков нужен отдельный VPS-патч веб-агента из ANDRIK-R1278-FB-TCP-AGENT.zip.
Сервер радио /opt/andrik-radio/radio247/server.mjs НЕ МЕНЯЕТСЯ.
Установка: загрузить полный ZIP сайта в штатную обновлялку. После публикации /cache-reset.html.
