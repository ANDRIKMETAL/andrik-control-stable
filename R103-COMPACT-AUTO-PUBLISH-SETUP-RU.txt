R103 — COMPACT AUTO PUBLISH · НАСТРОЙКА

Обязательный Cloudflare Secret:
GITHUB_SITE_TOKEN

Значения по умолчанию:
GITHUB_SITE_OWNER=ANDRIKMETAL
GITHUB_SITE_REPO=ANDRIK-Website
GITHUB_SITE_BRANCH=main
GITHUB_RELEASE_OWNER=ANDRIKMETAL
GITHUB_RELEASE_REPO=andrik-control-stable
GITHUB_RELEASE_BRANCH=main
GITHUB_RELEASE_ENABLED=true

Отдельный GITHUB_RELEASE_TOKEN можно добавить, но он не обязателен. Если его нет, используется GITHUB_SITE_TOKEN.
Токен должен иметь Contents: Read and write для обоих репозиториев.

Важно: GitHub commit автоматически запускает Cloudflare только если Pages связан с приватным репозиторием. Если связь не настроена, R103 сохранит commit и Release, а этап Cloudflare покажет ожидание ручного Deploy.
