R1498 — устранение 28-секундных тайм-аутов, вызванных последовательной обработкой множества видео в реакциях YouTube.
На каждом 2-минутном запуске проверяются лайки максимум 4 видео. Остальные видео обрабатываются в следующих циклах по вращающемуся окну, без сброса предыдущих счетчиков; накопленные новые лайки будут замечены позже.
Комментарии, LIVE-чат, подписчики, Cron Worker, радио, игра не изменены.
R1497 диагностические записи пока сохранены для проверки. Если при множественных новых лайках или сетевой задержке всё ещё есть тайм-ауты, потребуется дополнительное ограничение длительности.
