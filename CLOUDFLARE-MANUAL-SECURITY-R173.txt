ANDRIK SECURITY R173 — ЧТО УЖЕ СДЕЛАНО И ЧТО ПОДКЛЮЧИТЬ ВРУЧНУЮ

УЖЕ СДЕЛАНО В АРХИВЕ
1. ADMIN_KEY больше не должен сохраняться открытым в localStorage/sessionStorage.
2. После первого ввода создаётся подписанная HttpOnly + Secure cookie-сессия на 90 дней.
3. Старый сохранённый ключ автоматически мигрируется в cookie и заменяется безопасным маркером.
4. Вход владельца ограничен: 12 попыток за 10 минут на IP через D1.
5. Статические файлы /assets/* и OneSignal обходят Worker через _routes.json, экономя квоту.
6. HSTS, anti-frame, nosniff и ограничения разрешений закреплены в Worker/_headers.
7. Секрет Turnstile остаётся только на сервере.

НУЖНО ВКЛЮЧИТЬ В CLOUDFLARE ВРУЧНУЮ

ШАГ 1 — RATE LIMIT ДЛЯ ВХОДА ВЛАДЕЛЬЦА
Cloudflare Dashboard → andrikmetal.com → Security → WAF → Rate limiting rules → Create rule.
Название: ANDRIK Owner Login
Expression:
(http.request.method eq "POST" and http.request.uri.path eq "/api/control/owner-session")
Порог: 10 запросов за 1 минуту на IP.
Действие: Block.
Срок блокировки: 10 минут, если интерфейс тарифа позволяет выбрать.

ШАГ 2 — BOT FIGHT MODE
Security → Bots → Bot Fight Mode → ON.

ШАГ 3 — FREE MANAGED RULESET
Security → WAF → Managed rules → Cloudflare Free Managed Ruleset → ON.

ШАГ 4 — FAIL OPEN / CLOSED
Workers & Pages → проект ANDRIK → Settings → Runtime → Fail open / closed.
Рекомендация для проекта: Fail open, чтобы при исчерпании бесплатной квоты статический сайт продолжал открываться. Защищённые API при этом могут быть временно недоступны, но музыка и страницы не лягут целиком.

ВАЖНО
Не блокировать целые страны и ASN без реальной атаки. Это может закрыть доступ слушателям, Google и YouTube.
