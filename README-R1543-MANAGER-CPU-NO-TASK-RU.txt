ANDRIK R1543 — MANAGER CPU NO TASK

GUARD продолжает собирать показатели CPU и историю нагрузки.
MANAGER больше не создаёт задачи о высокой загрузке CPU.
При следующем обновлении MANAGER старая задача CPU удаляется из сохранённых задач, включая статус «В работе».
Push по CPU по-прежнему отключён.
WATCH, уведомления о сбоях эфира и остальные задачи MANAGER не меняются.
Сервер VPS, FFmpeg и радио не затрагиваются.

Установка: полный ZIP через обновление сайта. После установки обновить карточку MANAGER.
