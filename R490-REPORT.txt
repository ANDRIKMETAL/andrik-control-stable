ANDRIK CONTROL R490

Base: R489

FIXES
1. YouTube OAuth recovery:
   - If a revoked D1 refresh token exists, Worker retries the Cloudflare refresh-token Secret.
   - If the Secret works, stale D1 token is removed.
   - If all refresh tokens are revoked, Social Center shows one-tap “Переподключить YouTube”.
2. Instagram accuracy:
   - Unavailable Meta metrics are no longer displayed as false zeroes. They display “—”.
   - Daily Insights are requested for views, reach, profile_views, accounts_engaged, total_interactions, likes, comments, shares, saves.
   - 28-day scalar values remain authoritative where Meta provides them.
   - likes/comments fall back to recent-media like_count/comments_count when account Insights are unavailable/empty.
3. Instagram consistency:
   - Platform card uses the real 28-day scalar (e.g. 28-day reach), not the sum of daily reach.
   - Graph still shows daily reach when views are unavailable.
4. UI:
   - Instagram detail now includes Views.
   - Mixed platform total renamed “Общий итог” so reach is not mislabeled as views.
   - Version bumped to R490 and cache reset added.

No Instagram token is embedded in this archive.
