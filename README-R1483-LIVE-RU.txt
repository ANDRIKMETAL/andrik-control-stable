КАКОЙ АРХИВ УСТАНОВИТЬ СЕЙЧАС
SITE-R1483-INSTALL.zip — полный установочный сайт в формате STORE.
Выбрать в контрольке → «Обновить сайт» → дождаться проверки →
«Обновить сайт». Дождаться успешной публикации Cloudflare и обновить страницу.
Этот ZIP проверен штатным разборщиком из присланного R1482.
Никакой промежуточный R1481 или другой патч не требуется.

SITE-R1483-COMPRESSED.zip — тот же полный сайт, сжатый DEFLATE.
Использовать в контрольке ПОСЛЕ установки R1483: новый установщик проверяет
CRC и Git blob SHA-1 на устройстве, распаковывает ZIP и отправляет серверу
совместимый STORE. Не надо устанавливать оба архива подряд.
Для первой установки через старую контрольку выбирать именно INSTALL.zip.

ССЫЛКА И СЧЁТЧИКИ
— Новый адрес в главной RU/EN/SK/UK, меню, кнопках радио и контрольке.
— Сохранено открытие в приложении YouTube / ReVanced на Android.
— Верхние счётчики запрашивают именно U0bzXBNBs2Y.
— Дневные графики сегодня относятся только к выбранному новому эфиру.
— Сохранённый старый эфир и его кеш не подменяют новый.
— Выбор текущего эфира выполняется до LIMIT в SQL: многочисленные старые
  замеры не вытесняют новые. Добавлен индекс даты, videoId и времени.
— Архивные даты сохраняют исторические эфиры, базу просмотров для каждого
  videoId и реальные отсутствующие значения. Смена ссылки историю не удаляет.
— Первое наблюдение viewCount задаёт базу; весь накопленный счётчик не
  объявляется новыми просмотрами за день. Восстановление счётчика после
  временного уменьшения повторно не прибавляет уже учтённый прирост.
— Публичные просмотры и API viewCount могут различаться. Если публичный
  счётчик недоступен, используется viewCount именно нового эфира.
— Отсутствующий concurrentViewers остаётся «—», а настоящий ноль показывается
  нулём. Застаревший замер не объявляется текущим числом зрителей.

КОМПАКТНЫЙ ВЕРХ И УВЕЛИЧЕННЫЕ ГРАФИКИ
— Уменьшены заголовок, календарь и четыре дневных счётчика.
— «Сегодня» остаётся в одной строке с датой и стрелками.
— Графики получили больше высоты; на широком экране блок стал шире.
— Масштаб X: 1 час / 3 часа / 6 часов / весь день.
— Кнопки +/− приближают/отдаляют время до минимального окна 15 минут.
— Стрелки и ползунок перемещают временное окно.
— «Увеличить график» открывает большое окно с теми же инструментами.
  Закрывается кнопкой или Escape. Поддерживается поворот экрана.
— Нажатие на график показывает точное время реального замера, онлайн и
  прирост API. У столбика показываются границы его временного интервала.
— Время Europe/Bratislava; учтены сутки из 23/25 часов при переходе времени.
  Два осенних замера «02:30» имеют разные координаты и разные UTC-смещения.
— Пропуски больше 10 минут, неизвестный онлайн и смена videoId разрывают
  линию. Они не превращаются в выдуманный непрерывный участок.

ДОПОЛНИТЕЛЬНАЯ АНАЛИТИКА БЕЗ НОВЫХ ЗАПРОСОВ К YOUTUBE
— Прирост API за 60 минут до последнего сохранённого замера.
— Время первого максимума одновременных зрителей за выбранный день.
— Время последнего замера и отметка об устаревших данных.
— Среднее в графике — среднее число онлайн по доступным замерам, а не
  средняя длительность прослушивания. Прирост API не равен уникальным людям.
— Показы, CTR, удержание и источники рекомендаций не выдумываются из этих
  замеров: они по-прежнему доступны в YouTube Studio.

НАГРУЗКА И УСТАНОВЩИК
— Счётчики и графики используют один общий запрос аудитории при загрузке.
— Верхние счётчики обновляются примерно раз в минуту, история — раз в две.
— Снято принудительное fresh=1; сохранён короткий серверный кеш.
— Распаковка и полная проверка сжатых ZIP перенесены в браузер.
— В Worker STORE читается без повторного копирования всех байтов сайта.
— Пересобран быстрый манифест размеров и Git blob SHA-1 для всех файлов.
— Пояснение ошибки Cloudflare 1102 работает и с HTML-ответом вместо JSON.
— Во время проверки нельзя случайно заменить выбранный файл; публикация
  и Release используют тот же подготовленный и проверенный архив.
— Версии service worker и ссылки на изменённые скрипты обновлены.

ПРОВЕРКИ
Локально прошли: штатный парсер ZIP из R1482 и R1483; все CRC и SHA-1;
распаковка DEFLATE в браузерном модуле → STORE → старый установщик;
одинаковый состав двух архивов; обнаружение повреждённого/обрезанного ZIP;
реальные SQL-запросы через SQLite-адаптер D1; выбор нового videoId при
1100 старых замерах; архивные даты; baseline; временная коррекция viewCount;
сохранение null/0; сброс старого кеша; фиксация замеров; проверка доступа.

Клиентские скрипты проверены в локальном DOM-стенде: общий запрос,
счётчики, масштабирование/перемещение X, нажатие по времени, увеличение,
выбор дат, пустые периоды, разрывы линии и переходы летнего/зимнего времени.
SVG графика отдельно отрисован в растр. Полноценный визуальный прогон
страницы в браузере не выполнен: среда запретила локальную тестовую страницу.
Живые ответы YouTube/Cloudflare и установка на боевой сайт здесь не проверены.
