ОГРАНИЧЕНИЯ:
- YouTube может не предоставлять concurrentViewers. Сайт не может узнать число одновременно смотрящих без исходного показателя. В этом случае «Сейчас смотрят» и «Пик» остаются —, а вместо графика онлайна показывается график проверенных просмотров API.
- Цифры 2 и 167 могут отличаться из-за различий между YouTube Data API, YouTube Studio и публичной страницей и времени обновления.
