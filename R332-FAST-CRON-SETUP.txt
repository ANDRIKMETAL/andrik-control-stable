ANDRIK R332 — YouTube WebSub + 5-minute fallback

1. WebSub is automatic.
   After opening cache-reset-v55-00-final-r332.html while logged into Control,
   R332 sends the subscription request to Google's YouTube PubSubHubbub hub.
   If that immediate request cannot run, the normal central Cron retries it automatically.

2. Optional but recommended 5-minute backup Cron.
   In Cloudflare Dashboard, add ONE additional Cron Trigger to the same Worker:

   */5 * * * *

   IMPORTANT: keep the existing 15-minute central Cron. Do not replace it.
   R332 recognizes */5 * * * * and runs ONLY the lightweight YouTube release checker.
   All other Cron schedules continue to run the full central automation.

3. No phone/PWA background polling was added.
   WebSub and the 5-minute fallback run server-side in YouTube/Cloudflare.
