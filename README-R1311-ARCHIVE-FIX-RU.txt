ANDRIK R1311 FULL — АРХИВ КОММЕНТАРИЕВ: СЕССИЯ + ДИАГНОСТИКА ЗАГРУЗКИ

Основа: R1310 FULL. Монитор 74 релизных треков и его API НЕ изменены.

Причины:
- Архив использовал старую локальную проверку ADMIN_KEY, хотя вход уже переведён на 90-дневную owner-session.
- В R1310 не было тайм-аута для API и обратной связи при незагруженном JavaScript.

Исправления:
- Новая версия assets/comment-collection-r1311.js; старый r136 остаётся в архиве как совместимость.
- На запросы архива передаётся cookie существующей защищённой сессии владельца (credentials include). Менеджер owner-session подключён в странице до модуля архива.
- Никакого нового ADMIN_KEY в поле или в URL. Ключ вводится только в разделе «Служебное», если сессия недействительна.
- Тайм-аут 20 сек на каждый запрос + понятные ошибки с кнопкой повторной загрузки.
- При недоступном JS через 12 сек отображается диагностика вместо вечного «Загружаем…».
- Месяцы и лайки отображаются как раньше. Вся база D1 сохраняется, без миграций и удаления.
- SW контрольки получает новую версию, старый кэш можно безопасно очистить.

После установки FULL ZIP через обновление сайта открой:
https://control.andrikmetal.com/comment-collection.html
Если всё ещё ошибка, посмотри конкретное сообщение — теперь оно выведено на самой странице.
Если написано «Нужен вход владельца» — зайди в https://control.andrikmetal.com/service-admin.html и проверь защищённую сессию, затем вернись в архив.

ВАЖНО: Доступ к D1 и наличие комментариев в базе проверяются только на живом сервере; этот ZIP не создает старые комментарии сам по себе.
YouTube Topic-релизы могут не возвращать комментарии через API — это отдельная ситуация.
