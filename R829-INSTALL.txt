ANDRIK RADIO R829 GOLDEN NOCROP STABILITY BUILD

Install after uploading this complete build to the repository root:

curl -fsSL https://raw.githubusercontent.com/ANDRIKMETAL/andrik-control-stable/main/radio247/vm-lite/install-r829-golden-nocrop-r828-r827-r826-r821-preserved.sh | sudo env ANDRIK_SITE_BASE=https://raw.githubusercontent.com/ANDRIKMETAL/andrik-control-stable/main bash

R829 contains permanently in server.mjs:
- hard 1920x1080 direct fullscreen geometry; no crop, no pad, no aspect-ratio fallback
- R826: false r823-live-frame-stall service kill removed
- R826: genuine FLV/extract_extradata EOF output self-heal retained
- R827: once an insert reaches LIVE it is committed and cannot be replayed by late EOF/cleanup
- R828: prepared station inserts are never repeatedly full-decoded on the live path
- R821: station no-drain make-before-break
- R820: deterministic persistent master PTS lock
- R816: rawvideo frame-aligned persistent single x264 architecture
- R814: MP3 fade 1.10 -> black 0.20 -> fade in 1.15
- video queue 24, audio queue 8

R829 also installs one golden pre-start guard. Before EVERY radio start it restores the entire verified R829 server.mjs if an older/manual file replaced it. This intentionally makes R829 the stable baseline until a newer complete build is installed.
