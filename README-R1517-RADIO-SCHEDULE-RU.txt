ANDRIK SITE R1517 — РАДИО: КОНТРОЛЬКА И РАСПИСАНИЕ

Сохранены сервер R1516, visual-controls R1442 и album-pingpong R1479. Код самой A/V линии (RTMPS, MP3, clips, queue, fade, codec, PP) не переписывался.

СНАЧАЛА установи полный SITE-R1517-RADIO-SCHEDULE.zip через контрольку «Обновить сайт».
Затем загрузи VPS ZIP через «Радио» → «Сервер ZIP → R2» или передай на OVH/VPS обычным способом. После распаковки в папку архива запусти:

sudo bash INSTALL-R1517.sh

Проверка:
sudo systemctl status andrik-radio-schedule-r1517.timer --no-pager
sudo journalctl -u andrik-radio-schedule-r1517.service -n 80 --no-pager
sudo systemctl status andrik-radio.service --no-pager

Далее в контрольке: Радио → Автоматизация YouTube-радио. Выбор:
  А) Круглосуточный эфир — прежний режим.
  Б) Автоматический по часам — две независимые сессии.
По умолчанию сайт на «Круглосуточный эфир», поэтому установка НЕ останавливает текущий стрим.

ДНЕВНОЙ: 10:00–14:00 Europe/Bratislava, SILENT + NO ONE TO BECOME, клипы общие.
ВЕЧЕРНИЙ: 18:00–22:00 Europe/Bratislava, ILLUSION + OCEAN + TRIKA + BEYOND, клипы общие.
Можно изменить часы, включить/отключить сеансы, выбрать любые из 6 альбомов, включить клипы, название и описание. Текущее расписание опрашивается каждые 60 секунд по секретному уже спаренному Agent Token.

ВРЕМЕННАЯ ЗОНА: Europe/Bratislava с DST — не абсолютный UTC и не GMT+1 на весь год.
Архив: для каждой сессии через Google OAuth создаётся ОТДЕЛЬНЫЙ публичный broadcast, recordFromStart=true, enableDvr=true, enableAutoStop=true. После времени окончания сначала вызывается YouTube API complete, затем останавливается systemd-радио. Если API complete недоступно, автоостановка по концу сигнала служит резервом. Сохранение и зачёт часов решает YouTube.

ВАЖНО:
- На VPS должен быть уже привязан прежний web-agent с токеном в /etc/andrik-radio-web-r627.json или /etc/andrik-radio-web.json.
- На сайте Google OAuth YouTube должен иметь разрешение на управление трансляциями. Без него диспетчер не сможет создать/завершить видео; увидишь ошибку в логах.
- Перед переходом на расписание вручную заверши текущий длинный YouTube LIVE (который уже идёт с октября). Новая система не имеет права завершать произвольный старый эфир по неизвестному ID.
- YouTube 9:16: в YouTube Studio → Live Control Room → Dual Stream → Auto (16:9 source с автоматической вертикальной версией). Невозможно гарантированно включить это настройкой Worker/API. Проверь ПЕРЕД стартом первого нового эфира. Не нужны дополнительные FFmpeg на VPS.
- Пока не установлены обе части, НЕ переключай на расписание.
- Скрипт установки изменяет настройку systemd auto-boot: теперь стартом/стопом службы управляет ежеминутный таймер. При выборе «круглосуточно» он снова включает службу.
- Новые параметры альбомов активируются только в новом запуске радио, чтобы не сломать текущую песню. Нет выбранных MP3 — скрипт не подмешивает другой альбом.
- Таймер не зависит от работы браузера или телефона.
