ТЕКУЩИЙ ЭФИР
https://www.youtube.com/live/lpc9HfVs0NY
Исправлена привязка контрольки, публичных ссылок и сборщика к этому LIVE.
Успешные запросы контрольки теперь сохраняют минутные замеры в D1.
Проверка текущего ID получает свежую отметку времени при повторном подтверждении.
Замеры другого эфира не подмешиваются в графики текущего радио.
Просмотры LIVE, прирост viewCount за день и одновременные зрители показаны отдельно.
Локальный fallback не затирает публичные просмотры и свежий счётчик зрителей API.
Неизвестные показатели отображаются тире; предупреждение сборщика показывается явно.
Первый viewCount — база, прирост начинается со следующего реального замера.
Имеющиеся строки истории D1 не удаляются. Незамеченные ранее значения не выдумываются.
При отсутствии доступа YouTube API недоступные показатели останутся тире с предупреждением.

ТИТРЫ ЭФИРА

ИГРА
Три круглые полупрозрачные кнопки A/B/C расположены треугольником (A сверху).
На кнопках только буквы; комбинации, удержания и экранные подсказки паузы сохранены.
Враги строят путь вокруг стен, машин и ящиков; путь проверяется по поверхности пола.
Кэш маршрутов хранится в памяти и не увеличивает сохранения.
Атаки сохраняют проверку видимости цели. Дальние противники остаются на патрулировании.
Добавлены отдача корпуса/головы и усиленные искры попаданий; здоровье и урон не повышались.
Обложка в горизонтальном режиме, защита краёв CITY и предыдущие сохранения сохранены.
