ANDRIK R1532

Dreaming of Líra

• В гонке к маяку подсказка «Между буйками» вверху по центру,
  между показателями игрока и воротами. Она учитывает вырезы экрана.
• Если выбрана бита, Лира носит её рядом с гитарой за спиной.
  При появлении живого противника впереди или рядом Лира достаёт биту.
  Через секунду после исчезновения угрозы Лира убирает её.
  Короткое B и боевые приёмы сохраняют прежнее управление.

Установка сайта и WATCH

1. В контрольке открой «Обновление», выбери SITE-R1532-WATCH-GAME.zip,
   укажи R1532 и дождись завершения Deploy.
2. В «AI Агенты → ANDRIK WATCH → Подключение WATCH к VPS» скопируй
   команды и выполни их в Bash на VPS. Когда установщик попросит код,
   нажми «Получить код WATCH» и вставь код в терминал. Ввод скрыт.
3. Нажми «Обновить» в карточке WATCH и «Тест уведомления».
   Для получения push на телефоне нужна действующая подписка владельца.
   Синий глаз задан для карточки push. Силуэт глаза с короткой чертой
   используется в верхней строке Android, где система сама выбирает цвет.

Можно также распаковать этот ZIP на VPS и выполнить из его корня

   sudo bash radio247/watch-r1532/INSTALL.sh --apply

GUARD, подключённый в R1531, продолжит присылать замеры. Если GUARD ещё
не подключён, в его карточке есть свой код и команды. WATCH и GUARD
используют разные коды. Тест уведомления доступен сразу после публикации.

Как работает наблюдение

WATCH каждые 30 секунд читает состояние andrik-radio.service и локальный
GET http://127.0.0.1:8080/status. Использует счётчики и события, которые уже
отдаёт ANDRIK-SERVER-R1527.mjs. Файлы радио, расписание и очередь не меняются.
Штатная остановка радио видна как «Выключено». WATCH ждёт подтверждения
пропадания сигнала повторным замером. Свежие ошибки FFmpeg и переходов
учитываются по времени события. Автоматические уведомления WATCH приходят
с интервалом от пяти минут. Карточка показывает текущий и следующий
материал, а по давности отчёта видно потерю связи с агентом.

WATCH и GUARD отправляют push только на устройства владельца через уже
подключённый OneSignal. GUARD уведомляет о диске от 85%, RAM от 90% и
сбоях проверяемых служб. Сбой самого радио ведёт WATCH. Для работы агентов
используются Python 3, systemd и существующая база D1. OpenAI API и новые
платные подключения не требуются. WATCH проверяет сигнал на VPS, поэтому
состояние видео на стороне зрителя следует смотреть в самой трансляции.

Проверка и остановка WATCH

   bash radio247/watch-r1532/INSTALL.sh --check
   systemctl list-timers andrik-watch-r1532.timer --all --no-pager
   sudo journalctl -u andrik-watch-r1532.service -n 25 --no-pager
   sudo bash radio247/watch-r1532/INSTALL.sh --disable
