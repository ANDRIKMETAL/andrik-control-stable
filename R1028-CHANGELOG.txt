ANDRIK R1028 — LATEST SINGLES / RELEASE CHAIN FIX
Date: 2026-09-15

1. HOME PAGE — ALWAYS THE TWO NEWEST SINGLES
- Removed the hard pin for “Ты уже то” and “Всё есть Брахман”.
- The homepage now takes the first two newest unique singles from /api/music/singles.
- RU / EN / SK / UK home pages updated.
- Client-side protection also sorts newest-first and hides same-title duplicates.

2. ALL SINGLES — NO DUPLICATE TITLES
- /api/music/singles now reads only singles/ from R2, paginates the whole folder,
  sorts by published/uploaded time newest-first, and returns only one copy per normalized title.
- “All singles” therefore no longer renders two cards for the same song.

3. R2 — PHYSICAL DUPLICATE CLEANUP
- Added same-title duplicate cleanup for singles/.
- Older copies of the same normalized single title are removed; the newest copy is kept.
- Cleanup runs automatically when Releases opens with admin authorization,
  on every new single upload, and before manual “publish latest”.
- Added admin endpoint: /api/control/music/singles/dedupe-titles.

4. RADIO QUICK UPLOAD = FULL SINGLE RELEASE
- Upload from Radio Control still writes into singles/ but now shares the complete R1028 backend chain:
  R2 -> duplicate cleanup -> newest public Singles -> homepage latest two -> OneSignal PUSH.
- The same chain is used by Releases.

5. RELEASES UI
- The single WAV/MP3 -> MP3 320 -> R2 card is now the first card in Releases,
  above BEYOND and the other release tools.
- “Название сингла” opens empty instead of being filled with the previous latest single.
- After a successful upload the title, audio and cover fields reset to empty.
