ANDRIK SITE R1507 — ИСПРАВЛЕНИЕ ОТПИСОК YOUTUBE
Дата: 28 октября 2026
Основа: SITE-R1506-OWNER-PUSH-SEPARATE-FULL.zip

ИЗМЕНЕНИЯ
1. Исправлено условие обнаружения отписок в быстром контрольном опросе YouTube.
   Ранее при снижении числа подписчиков могло сработать условие отправки
   уведомления о ПРИРОСТЕ: current > min(previous, lastNotified). Это происходит,
   например, при previous=120, current=119, lastNotified=115.
2. Отписка теперь определяется сравнением текущего количества с предыдущим
   фактическим замером: current < previous (при previous > 0).
   Количество отписок = previous - current, не разность с последней отправленной
   нотификацией. Уведомление получает тип youtube-unsubscriber, красный значок.
3. Восстановительная ветка роста сохраняется, но только если current >= previous.
   Когда количество не изменилось, она всё ещё может догнать пропущенный push о росте.
4. Успешные отписки обновляют существующий маркер и историю. Ошибки доставки
   обрабатываются существующей очередью повторов R1505; защита от дублей R1506 сохранена.
5. Другие файлы приложения, SQL D1, Cron Worker, OneSignal конфигурация, радио,
   графики и игра не менялись. Не добавляются дополнительные YouTube API вызовы.

ВАЖНО
- В режиме Split Cron проверка подписчиков запускается каждые 15 минут, а не
  мгновенно. Между опросами рост и падение могут взаимно компенсироваться.
- YouTube Data API channels.statistics.subscriberCount округляется вниз до трёх
  значащих цифр для каналов от 1000 подписчиков. Например, уменьшение 1234->1233
  будет невидимым: оба значения API равны 1230. Реальное единичное уменьшение
  в этом случае нельзя гарантированно отследить по текущему источнику; точная
  статистика subscribersLost доступна в YouTube Analytics с задержкой.
- YouTube не раскрывает личность приватного отписавшегося человека.
- Эта сборка не устанавливается автоматически и не подтверждает статус
  работающего Central Cron, Cloudflare D1 и OneSignal на сервере.
