ANDRIK SITE R1291 — GAME 3D + FACEBOOK UI
БАЗА: SITE-R1290-LIRA-COMBAT-VISUAL-TEST.zip.

УСТАНОВКА
Используй обычный способ загрузки ZIP сайта. Перед обновлением сохрани копию сайта R1290.
Патч-архив накладывается поверх R1290 с сохранением структуры папок.
Полная сборка включает все файлы исходной R1290 плюс обновления R1291.
Ни один файл работающего VPS RADIO /opt/andrik-radio не редактируется скриптами в этом патче.

ИГРА
Сцены Портрет, City of Sleep (в переписке City of Streets) и Руины подхватывают новый модуль Lyra 3D R1291.
В рамках процедурной модели улучшены пропорции, голова, черты лица, волосы, одежда, детальная гитара, ремешок.
Гитара за спиной в покое, двухручная анимация при ударе. Кулаки активируются кнопкой ДЕЙСТВИЕ вдали от интерактивных объектов (или F на ПК), с чередованием рук.
Три удара комбо, апперкот подбрасывает противника, удар ногой отбрасывает дальше. Броски врагов, уклонения и отражение бросков гитарой.
Круглые полупрозрачные кнопки по макету, адаптация под ландшафт телефона. Окна, колёса, фары, двери и фасады машин/домов подробнее.

ВНИМАНИЕ: Это реальная процедурная Three.js модель, НЕ точная фотореалистичная GLB-копия концепт-арта. Для портретной схожести нужны отдельные UV-текстуры, rigged GLB и анимации; эти исходные 3D-активы не входят в присланный ZIP.

FACEBOOK LIVE
Верхние карточки «Смотрят сейчас» и «Просмотры эфира», бирюзовый объёмный график с периодами 1/6/24ч/весь эфир.
Название/описание и Persistent Stream Key помещены в закрытые спойлеры.
ВАЖНО: Graph API от Meta сейчас НЕ подключён: данные зрителей RTMPS/FFmpeg не выдаёт. Пока авторизованный Meta endpoint не доступен, отображаются прочерки и сообщение «Нет данных Meta», а не ложные нули. Текущие функции STOP/START/ключ/TCP оставлены без изменения.
