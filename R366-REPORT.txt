R367 — PUSH SUMMARY EXACT DATA FIX

Проблема:
- Push показывал реальные цифры, но экран «Сводка за сегодня» мог открыть
  старый/нулевой snapshot этого же периода.
- Ручная кнопка заново записывала snapshot, поэтому после ручной отправки цифры появлялись.

Исправлено:
- Каждый новый автоматический push получает уникальный snapshotId.
- Такой же механизм работает для ручной отправки.
- Push URL открывает именно snapshot, из которого было сформировано уведомление.
- Для старых push без snapshotId сервер сначала читает фактическую SENT-запись
  daily-summary из push_history, и только затем старое push_state.
- Push-экран всегда делает refresh=1 и больше не показывает старый localStorage cache до ответа сервера.
- Cache push-экрана разделён по snapshotId.
- R363 5-минутная доставка сводки сохранена.
- Карта целиком сохранена из R365: Россия zoom, city tap counter, стабильная жёлтая точка.
- R362 smooth-halos не возвращались.
