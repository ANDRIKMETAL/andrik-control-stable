ANDRIK METAL — R1485 · РАДИО: СТАТИСТИКА + УСТАНОВКА

Полный ZIP для штатной контрольки «Обновить сайт». Не распаковывать перед загрузкой.
Видео и работа VPS/FFmpeg не меняются. Прямой эфир не требуется перезапускать.

ИСПРАВЛЕНИЯ
1. Проверяется официальный videos.list: statistics.viewCount, likes, liveStreamingDetails.concurrentViewers.
2. Если онлайн отсутствует, дополнительно проверяется официальный liveBroadcasts.list со статусом OAuth владельца, строго для одного видео U0bzXBNBs2Y. Ответы другого эфира игнорируются. Если оба API не дали online — оставляем «—», не выдумываем ноль.
3. D1 сохраняет замеры, есть самостоятельный график накопленных просмотров LIVE. Графики по онлайн и приростам остаются; доступно увеличение и просмотр времени по точкам.
4. Первое измерение — начальная база. До второго числа новых просмотров сегодня неизвестно («—»). При известных замерах показывается реальный прирост, а не уникальные люди.
5. Сам архив R1485 сжат примерно до 13 МБ. В R1485 установщик после проверки манифеста больше не перепаковывает сжатый ZIP в STORE: следующие обновления передаются компактнее. ВАЖНО: при самом переходе с установленной R1484 её старый установщик ещё может временно распаковать и пересобрать ZIP до 19 МБ для отправки. Сервер повторно проверяет содержимое; время GitHub/Cloudflare Deploy зависит от сети и инфраструктуры.
6. Старые файлы управления эфиром и 3D игра сохранены.

ПОСЛЕ УСТАНОВКИ
Открой контрольку → Стрим YouTube → убедись, что вверху R1485.
Если в графике «сейчас смотрят» стоит «—», раскрой «Причина / источник» под статистикой: online YouTube может не возвращать даже владельцу.
Число просмотров LIVE относится ко всему текущему видео; «новые по API сегодня» — к разнице измерений за день, НЕ к уникальным зрителям.
История до первого сохранённого замера не восстановима задним числом.
Сбор в фоне зависит от работающего Cron Trigger и D1; ZIP не может сам включить триггер и не содержит токены Cloudflare/YouTube.

ЛОКАЛЬНАЯ ПРОВЕРКА
Проверить JS worker и браузерный синтаксис, ZIP CRC + манифест SHA, ссылки на новые ассеты. Тесты выполняются с имитацией API, без доступа к секретам сервера и реальным замерам YouTube.
