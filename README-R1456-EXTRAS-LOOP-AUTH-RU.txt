ANDRIK SITE R1456 — ЛУП ДЛЯ СИНГЛОВ / КАВЕРОВ И ИСПРАВЛЕНИЕ ВХОДА ПРИ ЗАГРУЗКЕ

Основа: полный R1455 с завершённой игрой на основе предоставленного R1454.
Главная всех четырёх языков и игра R1455 сохранены без изменений.

В шестой карточке «Covers / Extended / Singles» теперь есть:
- отдельное изображение и отдельный MP4;
- выбор изображения или зацикленного видео от 1 до 16 секунд;
- загрузка MP4 до 32 МБ, просмотр и удаление видео;
- переключение со следующей песни после подготовки файла.
Это один общий фон для синглов, каверов и Extended, отдельный от пяти альбомов.
В режиме студии пяти альбомов этот шестой слот тоже использует свой фон.

Исправлена авторизация загрузки MP4: XHR получает подписанный токен
владельца и cookie действующей сессии, как запросы контрольки.
Служебная отметка сохранённого входа не используется как ADMIN_KEY.
Worker принимает проверенную сессию даже при устаревшем Bearer-заголовке.
Неверные ключи и неподписанные токены по-прежнему отклоняются.
Повторный ввод ключа при действующей сессии не нужен.
Если сама сессия закончилась, войди в контрольку заново.

УСТАНОВКА
1. Выбери этот полный ZIP в штатном обновлении сайта. Не распаковывай.
2. Для воспроизведения шестого MP4 нужен отдельный VPS-патч:
   ANDRIK-R1456-EXTRAS-LOOP-16S-VPS.zip. Команда есть в его README-RU.txt.
3. После обновления заново открой страницу «Видео эфира».
4. В карточке 6 загрузи MP4 и выбери «Зацикленное видео · до 16 секунд».
Полная очистка кэша и данных входа не требуется.

Новое видео готовится в фоне; затем включится со следующего трека этого раздела.
Готовый ролик 8 секунд вперёд + 8 назад сохраняет все 16 секунд.
Никаких изменений главной и повторной переработки игры в R1456 нет.
