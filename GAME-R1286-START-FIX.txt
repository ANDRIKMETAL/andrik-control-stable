R1286 — исправление обработки запуска 3D

Установить этот полный архив сайта поверх R1285 обычным способом.
После загрузки открыть https://andrikmetal.com/game-refresh-r1286.html
Затем нажать Открыть игру. Ссылка принудительно выбирает graphics=3d.

Новые уровни больше не импортируются до запуска главного 3D-меню.
Добавлен загрузчик с обработкой ошибок загрузки модуля/запуска WebGL.
Молчаливое переключение на 2D при ошибке отключено; появится сообщение
с точным текстом ошибки и кнопкой повторного запуска.
Для мобильного главного меню отключено сглаживание, powerPreference default.
Сохранения не очищаются. Для намеренного запуска классики есть отдельная ссылка.

Проверка: полное встроенное игровое ядро + все зависимости главного 3D-модуля,
первый кадр, запуск игры и последующие кадры. Использовались Three.js и
имитация DOM/рендерера. Реальный Android/WebGL не проверены.
Точная исходная ошибка на устройстве пока неизвестна: снимки показывают
результат автоматического отката в 2D, но не исключение браузера.
Если появится сообщение об ошибке, его текст позволит точно определить причину.

Откат: game-backup-r1286/dreaming-of-lira.html вернуть в корень сайта.
Остальные новые файлы не мешают предыдущей версии.
