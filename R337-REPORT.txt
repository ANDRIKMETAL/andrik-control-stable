ANDRIK Control R337 — PER-LAYER MAP ANALYTICS
Date: 09.08.2026
Base: R336 — LIVE ECOSYSTEM MAP

Goal
Each ecosystem map layer now has its own country-activity list and its own monthly graph/archive, with clear titles that identify the active data source.

Layers
1. ВСЁ
   - list: «Топ стран по общей активности»
   - graph: «Динамика общей активности»
2. САЙТ
   - list: «Топ стран по посещениям сайта»
   - graph: «Динамика посещений сайта»
3. YOUTUBE
   - list: «Топ стран по просмотрам YouTube»
   - graph: «Динамика просмотров YouTube»
4. MUSIC
   - list: «Топ стран по музыкальной активности»
   - graph: «Динамика музыкальной активности»
5. PUSH
   - list: «Топ стран по новым push-подпискам»
   - graph: «Динамика push-аудитории»

Country activity — 7 + 7 days
- YouTube keeps the existing server weekly comparison.
- Site: unique visitors per country for the latest 7 days versus the preceding 7 days.
- Music: listen + MP3 download events per country for 7 days versus the preceding 7 days.
- Push: newly created active non-owner push subscriptions per country for 7 days versus the preceding 7 days.
- All: combines the four layer signals for the same periods.
- The round “7” button changes its aria-label/title to match the selected layer.
- The selected-country weekly badge follows the selected ecosystem layer instead of always describing YouTube.

Monthly graphs
- The calendar button now opens an independent archive for the current ecosystem layer.
- Each layer has its own monthly maximum history in localStorage.
- The old YouTube monthly archive is migrated automatically into the YouTube layer.
- July 2026 YouTube known maximum 16,564 remains preserved.
- Site/Music/Push/All archives begin filling from R337 as those layers are opened/updated.
- Header, chart caption and accessibility labels change with the selected layer.

Server
- /api/control/ecosystem-map now additionally returns weeklyCountries and previousWeekCountries for Site, Music and Push.
- Existing privacy remains: raw IP is not stored; R336 coarse geo behavior is unchanged.

Not changed
- accepted map geometry and country focus behavior
- portrait/landscape map dimensions
- five R336 ecosystem layer buttons
- updater workflow
- Guard / Cron / Push sending logic
- player / singles / MP3-WAV logic
