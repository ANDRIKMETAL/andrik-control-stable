ANDRIK R1313 · Архив + YouTube LIVE: быстрые запросы и сохранённые показатели

Поверх R1312, полный ZIP.

1. Архив: из обработчика чтения удалена несвязанная инициализация схемы OAuth/backup/release.
2. Архив: одна начальная загрузка выбранного месяца вместе со сводкой, вместо двух запросов подряд.
3. Архив: при кратковременном отказе API показывает последнюю сохранённую в текущей вкладке копию с явной пометкой даты. Существующая D1 не меняется и не очищается.
4. LIVE: обычная статистика читает OAuth liveBroadcasts/videos + серверный кэш просмотров. Медленный обход 7 страниц YouTube и десятков Analytics queries не выполняется при каждом обновлении. Для диагностики глубокий режим только по запросу deep=1.
5. LIVE: клиент перестал ставить fresh=1 каждые 30 сек, работает серверный 55-секундный кэш. Убрана дублирующая первая загрузка. Время ожидания 14 секунд, параллельные дубли запрещены.
6. LIVE: когда YouTube API недоступен, доступен локальный fallback и последние проверенные значения со статусом устаревания. Одновременные зрители из старой копии НЕ показываются как текущие.
7. История зрителей: страница не запускает тяжёлый самовосстанавливающий запрос YouTube. Сохраняется последние результаты D1 и маркируются устаревшие. При смене эфира выбирается ID последней пробы, без привязки к старому hard-coded ID.

НЕ затронуты: VPS, генерация радио, FFmpeg, Facebook, D1 таблицы и данные, 74 обнаруженных релиза, игра Лиры, соц. ссылки.

Установка через штатный обновлятор. Сделайте backup перед установкой. Очистка после установки: /cache-reset-r1277.html.
Проверить YouTube /radio-youtube-admin.html, архив /comment-collection.html.
