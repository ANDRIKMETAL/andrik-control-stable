ANDRIK METAL — R1488: ВРЕМЯ ПРОСМОТРА И ГЕОГРАФИЯ

Основа: переданный SITE-R1487-SHA-FIX-FULL.zip.
Текущий эфир: https://www.youtube.com/live/U0bzXBNBs2Y

Добавлено:
• В «Радио» и «Стрим YouTube» одинаковая сводка из одного API: среднее время
  одного просмотра, суммарные часы, общий текущий онлайн, страны и города.
• В «Стрим YouTube» график среднего времени / часов по дням. Можно выбрать
  7/28/90 дней, период по календарю, увеличить график и нажать точку для даты
  и значения. Пропуски не заменяются нулями; первый замер не выдумывается.
• Страны, города, просмотры и часы — официальный YouTube Analytics только
  выбранного видео, включая просмотры записи. Период одинаков для сводки,
  графика и географии. Среднее берётся из YouTube, а не из среднего по дням.
• Дата обработанных данных, момент запроса, ошибки подключения, частичные
  ответы и сохранённые данные явно показаны. Неудача географии не скрывает
  полученное время просмотра. Кэш и объединение запросов снижают нагрузку.
• «Города переходов с сайта» — отдельный раскрываемый блок за 60 минут / 24 ч,
  только для переходов в текущий эфир, с посетителями и числом кликов.

Что означают данные:
• YouTube Analytics приходит с задержкой. Новый эфир или свежий день могут
  ещё не иметь отчёта. Дни YouTube считаются в America/Los_Angeles, а даты
  оперативных замеров на существующем графике — в Europe/Bratislava.
• Это время на просмотр и общие часы, не журнал каждого человека. География
  YouTube за период — не местоположение зрителей, которые сейчас онлайн.
  YouTube может скрывать малые группы. Города показываются до 100 строк.
• «Смотрят сейчас» — отдельный свежий общий замер существующего Data API.
  Если API не передал число, показан прочерк, а не выдуманный ноль.
• Для Analytics нужно существующее подключение владельца канала. При ошибке
  разрешений открой «Проверить подключение YouTube». Уже выданные токены и
  ключи не меняются. Новые отчёты не доступны без входа владельца.

Установка:
1. Открой «Обновить сайт» в своей контрольке.
2. Выбери весь ZIP R1488, дождись окончания проверки и посмотри изменения.
3. Нажми «Обновить сайт». После установки открой «Радио» / «Стрим YouTube».

В ZIP нет дополнительной внешней папки. Текст сжат DEFLATE, уже сжатые медиа
хранятся без повторного сжатия. CRC и Git blob SHA-1 манифеста пересчитаны.
Исправления установщика R1487 и функции расписания видео сохранены.
Скорость установки зависит также от GitHub и сети; упакованный ZIP не может
гарантировать мгновенную установку. Эфир для чтения отчётов перезапускать
не требуется.
