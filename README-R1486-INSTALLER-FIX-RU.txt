ANDRIK METAL — R1486 — исправление проверки установщика и статистики R1485

Этот архив содержит полный сайт и все изменения статистики R1485.
При выборе ZIP новая контролька проверяет CRC и SHA-1 на устройстве, а на сервер отправляет для предварительного сравнения только список SHA (примерно 65 КБ). ZIP передаётся сжатым только на этапе публикации и проверяется сервером.

ВАЖНО: Установленная R1484 использует старый загрузчик. Если он зависает на HTTP 408, этот архив нельзя надёжно загрузить через старую контрольку. Сначала необходимо восстановить опубликованный загрузчик через GitHub, используя BOOTSTRAP ZIP с четырьмя файлами. Не нажимать UPDATE многократно при ошибке 408. Состояние эфирного VPS не меняется.

Файлы bootstrap:
- _worker.js (новый API /api/control/site-update/preview-manifest + R1485 статистика)
- site-update-admin.html (загрузчик с cache bust)
- assets/site-update-admin-r1483.js (сравнение только SHA через маленький запрос)
- assets/site-update-zip-r1483.js (не распаковывает сжатый архив перед отправкой)

После ручной загрузки bootstrap на main дождаться зелёного Deploy в Cloudflare и открыть страницу обновления заново с ?v=1486. Для будущих обновлений использовать полный ZIP R1486; прямое GitHub-действие не создаёт отметку Release через прежнюю контрольку.

Не считать отсутствие concurrentViewers нулём: YouTube API иногда не отдаёт его даже при активном эфире. Общие просмотры доступны отдельно.
